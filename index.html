Mirror 따라 하기

MIRROR STEP BY STEP

거울이에요. 오른쪽 절반만 남겨 두면 왼쪽 절반을 자동으로 만들어 주고, 오른쪽을 움직이면 왼쪽도 똑같이 따라 움직여요.

1. 정면으로 보기

` → Front

2. 편집 모드 + X-Ray

Tab 그다음 Alt Z. X-Ray를 켜야 뒤쪽 점까지 같이 선택돼요

3. 왼쪽 절반 선택

가운데 줄보다 왼쪽에 있는 점들을 드래그해서 네모로 잡아요. 가운데 줄의 점은 잡지 않아요

4. 삭제

X → Vertices. 오른쪽 절반만 남아요

5. Mirror 추가

Tab으로 나온 뒤, 속성 창 왼쪽 세로 아이콘 줄의 파란 스패너 → Add Modifier → Generate → Mirror

6. Clipping 체크

방금 생긴 Mirror 칸 안의 Clipping에 체크

7. 확인

편집 모드에서 오른쪽 점 하나를 G로 움직여 보세요. 왼쪽도 같이 움직이면 된 거예요
왜 쓰나얼굴과 몸은 좌우가 같아요. 한쪽만 만들면 작업량이 절반이고 좌우가 어긋날 일이 없어요. Clipping은 가운데 줄의 점이 거울 선을 넘지 못하게 붙잡아 줘요. 꺼져 있으면 가운데가 벌어져 틈이 생기거나 서로 파고들어 겹쳐요.

기본 큐브에는 가운데 줄이 없어요. 큐브로 연습하려면 먼저 Ctrl R로 세로 루프컷을 하나 넣어 가운데 줄을 만드세요. 강의의 Round Cube는 처음부터 가운데 줄이 있어요. 속성 창은 화면 오른쪽 아래 창이고, 왼쪽 가장자리에 탭 아이콘이 세로로 늘어서 있어요.

X-Ray가 꺼져 있어서예요. Alt Z로 켜요. 반쪽을 지울 때 꼭 필요해요

이어진 조각만 선택

UV 창에서 마우스를 올리고 L
연습큐브의 편집 모드에서 모서리 선 몇 개를 골라 Mark Seam을 한 뒤, A → U → Unwrap을 누르고 UV 창에서 전개도가 어떻게 펴졌는지 보세요. 심을 다르게 넣으면 펴지는 모양이 달라져요.

잘 보이는 곳(얼굴, 눈)은 조각을 크게, 안 보이는 곳(뒤통수)은 작게 둬요. 조각끼리는 붙이지 말고 조금 띄워요. 붙어 있으면 칠할 때 색이 옆 조각으로 번져요.

텍스처: 표면에 입히는 그림

TEXTURE PAINT

UV로 펼친 전개도 위에 색을 칠한 이미지예요. 강의는 이미지를 출력에 바로 연결해서 조명 영향을 받지 않게 해요.

재질 만들기

오른쪽 속성 창의 Material 탭 → New

이미지 만들어 연결

Shading 탭 → Shift A → Image Texture → New (2048) → Color를 Material Output에 연결

칠하는 화면

맨 위 탭에서 Texture Paint

브러시 크기 / 세기

F / Shift F 누르고 마우스 이동

한 번에 채우기

왼쪽 도구에서 Fill(페인트통) 선택 후 클릭

칠한 결과 보기

3D 화면에서 Z → Material Preview

이미지 저장

이미지 창 메뉴 Image → Save. 파일 저장과 별개예요
주의칠한 그림은 Ctrl S로 저장되지 않아요. Image → Save를 따로 해야 하고, 안 하면 Blender를 닫을 때 사라져요. 색이 안 칠해지면 그 오브젝트에 재질이 없거나, 이미지가 연결되지 않았거나, UV가 없는 거예요.

유저가 색을 고르게 할 파츠(머리카락, 눈동자, 옷)는 색을 칠하지 않고 회색조로 밝고 어두운 곳만 칠해요.

리깅: 뼈를 넣어 움직이게 하기

RIGGING

뼈(본)를 움직이면, 그 뼈와 같은 이름의 버텍스 그룹에 든 점들이 '웨이트' 값만큼 따라와요.

뼈대 추가

Shift A → Armature

뼈 이어 만들기

뼈대 선택 → Tab → 뼈 끝을 선택하고 E로 뽑기

이름 바꾸기

F2   좌우는 끝에 .L / .R

반대쪽 자동 생성

뼈 편집 상태에서 메뉴 Armature → Symmetrize

메시에 뼈대 연결

메시 선택 → Shift + 뼈대 선택 → Ctrl P → With Empty Groups

포즈 잡아 보기

뼈대 선택 → Ctrl Tab → 뼈 선택 후 R

포즈 초기화

포즈 상태에서 A → Alt R (회전) Alt G (이동)
웨이트웨이트는 0부터 1까지의 값이에요. 1이면 뼈를 완전히 따라가고 0이면 안 따라가요. 팔꿈치처럼 꺾이는 곳은 두 뼈가 나눠 가져요(가운데 0.5 / 0.5, 옆줄 0.8 / 0.2, 그 바깥 0.9 / 0.1). Weight Paint 화면에서 파랑이 0, 빨강이 1이에요.

웨이트 수치 입력과 옷에 웨이트 옮기기는 규칙이 정해진 작업이라 스크립트로 자동화할 수 있어요.
