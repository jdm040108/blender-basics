EP.11

입모양 완성: A, E, I, O, U 쉐이프 키

립싱크에 쓰는 다섯 가지 입 모양 A, E, I, O, U를 얼굴(Head)과 치아+혀 오브젝트에 같은 이름의 쉐이프 키로 만들어요.

강의 영상 열기
공통 작업 요령AEIOU최종 확인

공통 작업 요령

영상 내내 반복되는 기본 조작을 미리 익혀요.

  1. Value 1로 올리고 편집쉐이프 키

    Shape Keys에서 해당 키 선택 → Value를 1로 → 그 오브젝트만 선택 → Edit Mode
    Value가 1이어야 내가 고친 모양이 그대로 보여요.

  2. 입 주변 점 슬라이드이동·변형

    버텍스 선택 → G G → 마우스로 조금씩 옮겨요
    G를 두 번 누르면 점이 이어진 선을 따라 미끄러져요(엣지 슬라이드). 얼굴 굴곡을 지키면서 옮길 수 있어요.
    그냥 G로 올리면 옆에서 봤을 때 납작하게 변형돼요.

  3. 이어진 버텍스 한 번에 선택선택

    첫 버텍스 선택 → 끝 버텍스를 Ctrl + 클릭 → G G
    두 점 사이에 이어진 버텍스가 한 번에 선택돼요.

  4. Subdivision 표시 끄기모디파이어

    Modifiers 탭 → Subdivision 모디파이어의 뷰포트(모니터) 아이콘을 꺼요
    Subdivision은 면을 잘게 나눠 부드럽게 보여 주는 모디파이어예요. 끄면 실제 점 위치가 잘 보여서 입 모양 고치기가 편해요.
    옆 라인이나 그림자를 확인할 때는 다시 켜요.

  5. 목표 형태 스케치기타

    Annotate 도구로 만들 입 모양을 먼저 그려요
    선을 보고 맞추면 모양 잡기가 쉬워요.

  6. 옆 라인 스케치 후 맞추기이동·변형

    Basis 상태의 옆 라인(턱, 입술 실루엣)을 Annotate로 그려 둠 → 해당 키에서 버텍스 선택 → G Y로 선에 닿게
    입을 벌려도 옆얼굴 윤곽이 원래와 같아야 예뻐요. G 다음 Y는 앞뒤로만 움직여요.

  7. 햇빛 돌려 그림자 점검음영·노멀

    Viewport Shading 4번째(Rendered) → 햇빛(Sun) 선택 → R R → 마우스로 돌려 봐요
    R을 두 번 누르면 모든 방향으로 자유롭게 돌아가요(트랙볼 회전). 빛 방향을 바꿔 가며 그림자가 우글우글하지 않은지 봐요.
    얼굴에 그림자가 절반쯤 찰 때 문제가 잘 보여요.

  8. 그림자 이상한 곳 펴기메시 편집

    주변 버텍스를 G 또는 G G로 펴거나, Smooth 툴로 문제 부위만 문질러요
    점 간격이 고르면 그림자도 매끈해져요.
    실제 방송에서는 얼굴에 빛이 예쁘게 드는 방향으로 조명을 둬요. 괴물 같지만 않으면 적당히 타협해도 된다고 해요.

  9. 입천장 올리기이동·변형

    입천장(입속 동굴 윗면) 쪽 버텍스를 선택해서 같이 올려요
    입속이 어둡거나 꼬여 보일 때 해결돼요.
키얼굴(Head) 만드는 법치아/혀 만드는 법
A+ 로 새로 생성 (가장 큰 입)+ 로 새로 생성
EA 0.8 → New Shape from Mix, 가로로 넓힘A 0.8 → New Shape from Mix
IE 1 → New Shape from Mix+ 로 새로 생성 (Basis에서 시작)
O+ 로 새로 생성 (Basis에서 시작)E 1 → New Shape from Mix
UO 1 → New Shape from MixA 1 → New Shape from Mix
강사의 팁
  • 대상은 Head(얼굴, 입속 동굴 포함)와 치아+혀 오브젝트예요. 둘 다 같은 이름의 키를 만들고 Mio3 ShapeKey로 연동해요(Ep.10).
  • 쉐이프 키 이름은 알파벳 대문자 한 글자 A, E, I, O, U 예요.
  • 버추얼 캐릭터라서 만화적 허용이 돼요. 리얼한 발음 모양보다 귀엽고, 서로 다른 모음이라는 것만 구분되면 돼요.
  • 모든 표정에서 완벽한 그림자는 어렵다고 해요.
  • 버텍스 이동량은 대부분 화면으로만 보여 줘요. 수치는 화면을 보고 맞추세요.

A

0:00~10:24

가장 크게 벌어지는 A 입 모양이 얼굴과 치아/혀에 만들어져요.

  1. A 키 만들기쉐이프 키

    Head 선택 → Data 탭 → Shape Keys → + → 생긴 Key 2 의 이름을 A 로
    A는 다섯 모음 중 가장 크게 벌어지는 입이에요.
    강사는 살짝 미소 짓는 느낌으로 벌려요. 입이 클수록 더 귀엽다고 해요.

  2. A=1로 Edit Mode쉐이프 키

    Head만 선택 → A 의 Value를 1로 → Edit Mode
    A 키에 입 벌린 모양을 저장해요.

  3. 입 가장자리부터 벌리기이동·변형

    입 가장자리 버텍스부터 차례로 선택 → G G로 벌려 자리를 만들고, 입을 조금씩 크게 벌려요
    바깥부터 자리를 넓혀야 입을 크게 벌릴 공간이 생겨요.
    강의 자막에 수치가 없어요. 화면을 보고 맞추세요.

  4. 꼬인 면 확인음영·노멀

    뷰포트 색을 Random으로 바꾸고 Viewport Overlays → Face Orientation 을 켜요
    입속 면이 꼬였는데 색 때문에 안 보일 때 써요. Face Orientation은 면의 앞은 파랑, 뒤는 빨강으로 보여 줘요.

  5. Clipping 풀고 밀기모디파이어

    Modifiers 탭 → Mirror 모디파이어의 Clipping 체크 해제 → 꼬인 부분을 G로 옆으로 밀어요
    Clipping은 가운데 점이 중앙선을 못 넘게 붙잡는 옵션이에요. 걸려서 안 움직일 때 잠시 풀어요.
    Clipping에 걸리지 않으면 풀 필요 없어요.

  6. 입안 공간 넓히기이동·변형

    입속 버텍스를 선택해서 안쪽으로 밀어 넣어요
    입을 벌렸으니 입안 공간도 넓어져야 해요.
    옆에서 봐서 입속이 얼굴 밖으로 뚫고 나가지 않았는지 확인하세요.

  7. 옆 라인 다듬기이동·변형

    Subdivision 뷰포트 표시를 켜고 옆에서 봄 → 튀어나온 턱 라인을 G Y로 수정 → 앞으로 튀어나온 입꼬리도 Y로 밀어 넣어요
    턱선이 반듯하고 귀여운 선이 되게 해요.

  8. 그림자 확인 후 미세 수정음영·노멀

    햇빛 선택 → R R로 돌려 입 주변 그림자 확인 → 입 주변을 G G로 조금씩 수정
    빛 방향을 바꿔도 입 주변 그림자가 지저분하지 않게 해요.

  9. 치아/혀에 A 키 만들기쉐이프 키

    치아/혀 오브젝트 선택 → Data 탭 → Shape Keys → + 두 번(Basis, Key 1) → Key 1 이름을 A 로
    입이 벌어지면 치아와 혀도 따라 움직여야 해요.

  10. A 연동 확인쉐이프 키

    Head를 선택하고 A 값을 내렸다가 1로 올려요
    Mio3 ShapeKey 연동으로 치아의 A도 1이 돼요.

  11. 윗니만 선택선택

    치아 오브젝트 Edit Mode → 윗니 버텍스 하나 선택 → Ctrl L
    Ctrl+L은 선택한 점과 이어진 덩어리 전체를 선택해요. 윗니만 잡을 수 있어요.

  12. 윗니 위치, 회전 조정이동·변형

    윗니를 옮기고 회전해서 살짝 보이게 맞춰요
    A 발음에서 윗니가 살짝 보이는 것이 좋아요.
    강의 자막에 수치가 없어요. 화면을 보고 맞추세요.

  13. Mirror Clipping 체크모디파이어

    치아 오브젝트 → Modifiers 탭 → Mirror 모디파이어 → Clipping 체크
    회전하니 미러 중앙이 쪼개졌어요. Clipping을 켜면 가운데가 붙어 있어요.

  14. 아랫니 내리기이동·변형

    아랫니를 선택해서 턱을 뚫고 나가지 않게 내려요
    입이 벌어진 만큼 아랫니도 내려가야 해요.

  15. 아랫니 크기 맞추기이동·변형

    아랫니 선택 → S Y로 조정
    너무 작아 보여서 빈 공간만큼 보이게 해요. S 다음 Y는 앞뒤(Y축)로만 크기를 바꿔요.

  16. 혀 숨기기화면

    혀 선택 → H
    비례 편집이 혀를 건드리지 않게 숨겨요.

  17. 아랫니 아랫면 밀어 넣기이동·변형

    Proportional Editing을 켜고 아랫니 아랫면을 Y 방향 안쪽으로 밀어 넣어요
    아랫면이 턱 밖으로 삐져나올 것 같을 때 해요.
    치아가 살 속으로 얼마나 파고들었는지는 방송에서 절대 안 보여요. 편한 쪽으로 하면 돼요.

  18. 혀만 남기기화면

    Alt H로 전부 다시 보이게 → 치아를 선택해 H로 숨겨요
    이번에는 혀만 작업해요.

  19. 혀 내리고 키우기이동·변형

    혀를 내림 → 전체를 X 방향으로 조금 키움 → G Y와 각도 조정
    A 발음에서 혀는 치아 밖으로 나오지 않고 치아 안쪽에 걸리는 느낌이에요.
    혀가 치아에 파묻혀 보이지 않게 주의하세요.
강사의 팁
  • 입속은 단색으로 진행해요. 입천장 주름 같은 표현은 텍스처로 칠할 영역이에요.

E

10:33~13:27

A보다 조금 작고 가로로 긴 E 입 모양이 생겨요.

  1. A를 0.8로쉐이프 키

    Head 선택 → Shape Keys에서 A 의 Value를 0.8로
    E는 A와 비슷하지만 턱이 덜 내려가는 조금 작은 입이에요.
    0.8은 강사 값이에요. 원하는 만큼 맞춰도 돼요.

  2. New Shape from Mix쉐이프 키

    Shape Keys 목록 오른쪽 아래 화살표(▼) 메뉴 → New Shape from Mix
    지금 화면에 보이는 섞인 모양을 그대로 새 키(Key 3)로 복제해요.

  3. A를 0으로, 이름 E로쉐이프 키

    A 의 Value를 0으로 → 새 키 이름을 E 로
    원본 값을 되돌려 두지 않으면 두 키가 겹쳐 보여요.

  4. 치아도 같은 방법으로 E쉐이프 키

    치아 오브젝트 선택 → A 를 0.8로 → ▼ 메뉴 → New Shape from Mix → A 를 0으로 → 이름 E
    치아/혀에도 같은 이름의 키가 있어야 연동돼요.

  5. 핀으로 A와 E 비교쉐이프 키

    Shape Keys 패널의 핀 아이콘을 켬 → 목록에서 A, E를 번갈아 클릭 → 확인 후 핀 해제
    핀을 켜면 선택한 키만 보여서 클릭만으로 두 모양을 비교할 수 있어요.

  6. 입을 가로로 넓히기이동·변형

    E 키에서 Edit Mode → 입꼬리 쪽을 G로 벌려요
    A와 차이가 없으면 예쁘지 않아요. A의 가로 폭만큼 넓혀서 A보다 가로로 긴 입으로 만들어요.

I

13:32~24:09

입꼬리가 둥글게 벌어진 I 입 모양과, 입을 가득 채운 치아가 만들어져요.

  1. E에서 I 만들기쉐이프 키

    Head에서 E 를 1로 → ▼ 메뉴 → New Shape from Mix → Key 4 이름을 I 로 → E 를 0으로
    E 모양에서 출발하면 빨라요.

  2. 이 모양 잡기이동·변형

    I 키에서 Edit Mode → 아래쪽을 내리고 입꼬리를 당기면서 주변 점도 같이 옮겨요
    만화적으로 입꼬리 쪽이 둥글게 벌어진 '이' 모양이에요.
    강의 자막에 수치가 없어요. 화면을 보고 맞추세요.

  3. Basis 옆 라인 그리기기타

    Basis 상태의 옆모습 라인을 Annotate(노란 선)로 그려요
    원래 옆얼굴 윤곽을 기준선으로 남겨요.

  4. 아랫입술을 선에 맞추기이동·변형

    I=1에서 들어가 있는 부분을 Y로 꺼내고, 아랫입술 쪽이 선에 닿게 G Y
    옆에서 봤을 때 윤곽이 Basis와 같아야 자연스러워요.

  5. Blend from Shape로 되돌리기쉐이프 키

    아랫입술, 턱 부분 버텍스 선택 → 메뉴 Vertex → Blend from Shape → 왼쪽 아래 옵션에서 Shape를 Basis 로, Add 체크 해제 → Blend 값 조절
    선택한 부분만 Blend 값만큼 원래 Basis 모양으로 돌아가요. 움직이면 안 되는 부위를 되돌릴 때 써요.
    강사는 일부만 적용했어요. Blend 수치는 자막에 없어요. 화면을 보고 맞추세요. (16:12)

  6. Quick Favorites에 등록파일·설정

    메뉴 Vertex → Blend from Shape 항목에 우클릭 → Quick Favorites에 추가. 이후 Q로 불러요
    자주 쓰는 기능이라 Q 메뉴에 넣어 두면 빨라요.

  7. 윗입술, 입꼬리 다듬기이동·변형

    화면을 여러 각도로 돌려 보면서 직접 늘린 윗입술과 입꼬리를 수동으로 다듬어요
    되돌릴 수 없는 부분은 손으로 맞춰요.

  8. 그림자 점검음영·노멀

    Viewport Shading 4번째(Rendered) → 햇빛 선택 → R R로 돌려 봄 → 2번째(Solid)로 복귀
    I 모양에서도 그림자가 깨끗한지 봐요.

  9. 치아에 I 키 새로 만들기쉐이프 키

    치아 오브젝트 선택 → Shape Keys → + → 이름 I → Value 1
    치아의 I는 Basis에서 새로 시작해요.

  10. 혀 숨기기화면

    Edit Mode에서 혀 선택 → H
    치아만 고치려고요.

  11. 치아 가로로 키우기이동·변형

    치아 선택 → S X
    S 다음 X는 좌우로만 크기를 키워요. 치아가 입을 가득 채우게 해요.

  12. 치아 끝부분 옆으로이동·변형

    X-Ray를 켜고 치아 끝부분을 Proportional Editing으로 옆으로 옮겨요
    입꼬리 쪽까지 치아가 차 보이게 해요.

  13. 입속 동굴만 격리선택

    Head Edit Mode → 입속 동굴 버텍스 하나 선택 → Ctrl L → 왼쪽 아래 옵션 Delimit에서 Seam 체크 → Shift H
    치아가 커졌는데 가려지는 건 입속 동굴이 작아서예요. Seam(UV 자르는 선)을 경계로 동굴만 선택하고, Shift+H로 나머지를 숨겨요.

  14. 동굴 넓히기이동·변형

    치아와 부딪히는 동굴 부분을 선택해서 넓혀요
    치아가 동굴 벽에 가려지지 않게 해요.

  15. 숨긴 것 다시 보이기화면

    Alt H
    동굴 작업이 끝났으니 얼굴 전체를 다시 봐요.

  16. 동굴 주변 그림자 완화음영·노멀

  17. 치아 흰색 영역 넓히기이동·변형

U

O에서 아랫입술이 올라간 가로 타원 U가 만들어지고, O와 U의 볼살이 Basis에 고정돼요.

  3. 범위 줄이고 Y로 빼기이동·변형
