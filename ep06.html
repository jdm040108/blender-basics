EP.06

트윈테일 머리 모델링

평면(Plane), 커브(Path), 구(UV Sphere)를 써서 앞머리부터 뒷머리, 트윈테일까지 머리카락 덩어리를 하나씩 만들어요. 이번 편은 모델링만 하고 색은 다음 편에서 칠해요.

강의 영상 열기
머리카락 제작 방식 요약참조 이미지앞머리앞 옆머리뒷면 메꾸기 (닫힌 입체로 만드는 법)윗머리 / 옆 덮는 머리두피애교머리(꼬랑지)가느다란 옆 가닥바보털(안테나), 커브 방식 1뒷머리, UV Sphere 조각뒷머리 덧댄 삐친 가닥트윈테일, 커브 방식 2트윈테일 삐친 가닥

머리카락 제작 방식 요약

이번 편에서 머리카락을 어떤 방법과 순서로 만드는지 알게 돼요.

순서만드는 것방식
1앞머리Plane
2앞 옆머리Plane
3앞머리와 앞 옆머리 뒷면 메꾸기Edge Crease + 면 채우기
4윗머리 / 옆 덮는 머리Plane
5두피Head 면 복제·분리
6애교머리(꼬랑지)Plane
7가느다란 옆 가닥Plane
8바보털Path + Extrude
9뒷머리 3조각UV Sphere 조각
10뒷머리 덧댄 삐친 가닥 2개뒷머리 가닥 복제
11트윈테일 본체Path + Depth
12트윈테일 삐친 가닥 3개트윈테일 면 복제
강사의 팁
  • 기본은 메시(Plane)예요. 평면을 세워 루프 컷 → 휘어서 형태 → Mirror + Subdivision + Auto Smooth 80도 → 볼륨(Alt+S) → 가장자리 Edge Crease → 뒷면을 메꿔 닫힌 입체로 만들어요.
  • 커브(Path)는 2곳에만 써요. 바보털(안테나)은 Path + Extrude(납작한 리본), 트윈테일은 Path + Depth(둥근 튜브)예요. 둘 다 Resolution을 낮춘 뒤 메시로 바꾸고 그 뒤는 메시로 편집해요.
  • 뒷머리는 UV Sphere에서 조각을 떼어 만들어요.
  • 두피(머리 속)는 Head 메시의 두피 면을 복제해 떼어 낸 뒤 부풀려요.
  • 이번 편에는 UV, 텍스처, 쉐이더, 리깅, 애드온 사용이 없어요.
  • 강의 자막에 Ctrl E로 섭디비전이라고 나오는 곳이 있지만 Subdivision 단축키는 Ctrl+1로 봐요(자막 오기로 추정).
  • 강의에서 Q 눌러서 거울이라고 하는 것은 Quick Favorites(Q)에 등록해 둔 Mirror 모디파이어 추가로 보여요. 세모 버튼은 Subdivision 모디파이어의 On Cage 버튼이에요.

참조 이미지

0:00~1:10

머리카락과 옷이 그려진 정면, 옆, 뒤 참조 이미지가 깔려 있어요.

  1. 정면 이미지 교체파일·설정

    ` → Front → 기존 참조 이미지(대머리 버전)를 Cloth-Front.png 로 바꿔요
    머리카락과 옷이 그려진 그림을 보고 따라 만들어야 해요.

  2. 옆 이미지 교체파일·설정

    ` → Right (강의는 넘패드 3) → Cloth-Side.png 로 바꿔요
    옆에서 본 머리카락 모양을 맞출 때 써요.

  3. 뒷모습 이미지 불러오기파일·설정

    뒷모습 이미지도 불러와요
    뒷머리를 만들 때 길이와 끝 모양을 맞춰요.
    강의 자막에 뒷모습 파일 이름이 없어요. 준비 파일에서 찾아 쓰세요.

  4. 눈 감긴 상태로 두기기타

    얼굴 모델은 눈을 감긴 상태로 두고 작업해요
    강사가 이 상태로 작업해요.

앞머리

1:10~6:45

끝이 갈라지고 가운데가 볼록한 앞머리 덩어리가 있어요.

  1. Plane 세우기메시 편집

    Shift A → Plane → R X 90 → 크기를 앞머리에 맞춰요
    Plane은 평평한 네모 면이에요. 머리카락 한 덩어리는 이 면을 세워서 시작해요.

  2. 위아래 길이 맞추기이동·변형

    Edit Mode → 위는 머리 꼭대기 쪽, 아래는 앞머리 끝 높이로 옮겨요
    앞머리가 시작하고 끝나는 높이를 참조 그림에 맞춰요.

  3. 가로 루프 컷 4개메시 편집

    Ctrl R → 가로 방향 4개
    줄이 있어야 면을 이마 곡면을 따라 휘게 할 수 있어요.

  4. 이마 따라 휘게 하기이동·변형

    ` → Right → X-Ray 켜기 → 피벗 Median Point → 각 줄을 G Y 로 옮겨요
    옆에서 보면서 줄을 앞뒤로 옮겨 이마 곡면을 따라가게 해요.
    균일할 필요 없어요. 볼륨감만 살리면 돼요.

  5. 반으로 자르고 Mirror모디파이어

    세로로 반을 잘라 한쪽을 지워요 → Mirror 모디파이어 추가
    Mirror는 한쪽만 만들면 반대쪽을 거울처럼 만들어 줘요.

  6. 나뭇잎 모양 만들기이동·변형

    위쪽 점 선택 → S X 로 좁혀요
    위는 모이고 아래로 퍼지는 나뭇잎 모양이에요. 끝에서 한 번 갈래가 나뉘어요.

  7. Auto Smooth 80도음영·노멀

    우클릭 → Shade Auto Smooth → 80
    면이 각져 보이지 않고 매끈해 보여요. 강사는 약속의 80도라고 불러요.

  8. Subdivision과 On Cage모디파이어

    Ctrl 1 → Subdivision 모디파이어의 On Cage 버튼(세모) 켜기
    Subdivision은 면을 잘게 나눠 둥글게 해 줘요. On Cage를 켜면 둥글어진 모양 위에서 바로 점을 잡을 수 있어요.

  9. 세로 루프 컷 추가메시 편집

    Ctrl R → 세로 방향 약 2개
    갈래를 나눌 자리에 선이 있어야 해요.

  10. 갈래 벌리기메시 편집

    갈래가 될 위치의 엣지 선택 → V
    Rip은 선을 따라 면을 찢어 벌리는 기능이에요. 머리카락 끝이 갈라져요.

  11. 벌어진 위쪽 닫기메시 편집

    Ctrl R 로 루프 컷 추가 → 너무 벌어진 위쪽 점들을 병합해 닫아요
    끝만 갈라지고 위쪽은 붙어 있어야 해요.

  12. 갈래 가운데 루프 추가메시 편집

    Ctrl R → 갈래 조각의 가운데에 세로 루프
    부풀릴 가운데 줄이 있어야 볼륨을 줄 수 있어요.

  13. 볼륨 주기이동·변형

    부풀릴 점들 선택 → Alt S
    Shrink/Fatten은 점을 면의 바깥 방향으로 밀어 부풀려요. 가운데가 볼록한 덩어리가 돼요.

  14. 옆에서 Y로 내밀기이동·변형

    ` → Right → 점 선택 → G Y
    옆에서 볼 때 모자란 볼륨은 직접 앞으로 내밀어요.

  15. 옆쪽 끝 오므리기이동·변형

    옆쪽 앞머리 끝 점을 안쪽으로 옮겨요
    끝이 안으로 오므라들어야 얼굴을 감싸는 느낌이 나요.

앞 옆머리

7:00~14:50

머리 옆면을 감싸는 앞 옆머리가 있고, 헤어가 Hair 컬렉션에 모여 있어요.

  1. Plane 세우기메시 편집

    Shift A → Plane → R X 90 → 크기와 Y 위치를 맞춰요
    앞머리와 같은 방식으로 시작해요.

  2. 루프 컷 4개로 휘게메시 편집

    Ctrl R → 4개 → 줄을 옮겨 휘게 해요
    머리 곡면을 따라 휘어야 해요.

  3. 옆으로 길게 당기기이동·변형

    옆(뒤쪽) 점들을 길게 당겨 머리 옆면을 감싸게 해요
    옆에서 보면 허전해서 옆면까지 덮어 줘요.

  4. 트랜스폼 적용 후 Mirror모디파이어

    Ctrl A → All Transforms → Mirror 모디파이어 추가
    크기와 회전 값을 굳혀 줘야 Mirror가 제자리에 붙어요.
    Mirror가 엉뚱한 곳에 붙으면 이걸 안 한 거예요.

  5. Subdivision 걸기모디파이어

    Ctrl 1
    면을 둥글게 만들어요.

  6. 가운데 중심선 추가메시 편집

    Ctrl R → 가운데에 루프 1개
    나중에 부풀릴 가운데 줄이에요.

  7. On Cage와 Auto Smooth음영·노멀

    Subdivision 모디파이어의 On Cage 버튼(세모) 켜기 → 우클릭 → Shade Auto Smooth → 80
    둥글어진 모양 위에서 편집하고, 표면을 매끈하게 보이게 해요.

  8. 위에서 보며 맞추기이동·변형

    ` → Top → 옆머리를 밀고 당겨 맞춰요
    위에서 봤을 때 앞머리가 너무 튀어나와 보이지 않게 해요.
    참조 그림과 완벽히 같지 않아도 느낌이 비슷하면 돼요.

  9. 끝 갈래 만들기메시 편집

    Ctrl R 로 루프 컷 → 끝 엣지 선택 → V
    옆머리 끝도 갈라지게 해요.

  10. 갈래에 볼륨 주기이동·변형

    Ctrl R 로 가운데에 루프 → 선택 → Alt S
    갈래마다 가운데가 볼록해야 통통한 머리카락이 돼요.

  11. 어색한 곳 Smooth메시 편집

    어색한 점 선택 → Smooth
    울퉁불퉁한 곳을 펴 줘요.

  12. Hair 컬렉션에 모으기파일·설정

    헤어 오브젝트를 Hair 컬렉션으로 옮겨요
    머리카락 조각이 많아지니 한곳에 모아 관리해요.

  13. 로컬 뷰로 헤어만 보기화면

    헤어 선택 → /
    선택한 것만 화면에 남겨 헤어끼리만 확인해요.
    강의는 넘패드 / 를 써요.

  14. 색을 Random으로화면

    뷰포트 셰이딩 옵션 → Color → Random
    오브젝트마다 다른 색으로 보여서 조각이 구분돼요.
    조각이 구분이 안 될 때 켜요.

  15. 돌려 보며 수정하기화면

    뷰를 빙글빙글 돌려 딱딱해 보이는 각도를 찾아 고쳐요
    한 방향에서만 보면 각진 곳을 놓쳐요.

뒷면 메꾸기 (닫힌 입체로 만드는 법)

14:50~20:45

앞머리와 앞 옆머리가 뒷면까지 막힌 입체가 되어 있어요.

  1. 가장자리에 Edge Crease메시 편집

    가장자리(외곽) 엣지 전부 선택 → Shift E → 1
    Edge Crease는 Subdivision을 걸어도 그 선이 둥글게 뭉개지지 않게 잡아 줘요. 머리카락 윤곽이 날카롭게 남아요.
    형태가 확정된 뒤에 하세요.

  2. 피벗 Active Element파일·설정

    피벗 메뉴 → Active Element → Proportional Editing 끄기
    마지막에 고른 점을 중심으로 모이게 해요.

  3. 가장자리 모아 붙이기메시 편집

    마주 보는 가장자리 점 선택 → 병합하거나 S 로 모아 붙여요
    뒷면을 막으려고 양쪽 가장자리를 뒤에서 만나게 해요.

  4. 면 만들고 정리하기메시 편집

    점 선택 → F → J 로 정리
    F는 면을 채우고 J는 점 사이에 선을 그어 면을 나눠요.

  5. 앞머리 가장자리 뽑기메시 편집

    앞머리 가장자리 엣지 선택 → E X → Mirror 모디파이어의 Clipping 켜기
    앞머리는 붙일 상대 엣지가 없어서 면을 뽑아요. Clipping은 점이 가운데 선을 넘지 않고 붙게 해 줘요.

  6. 안쪽 엣지 크리즈 빼기메시 편집

    새로 뽑은 안쪽 엣지 선택 → Shift E → 0
    안쪽 선까지 날카로우면 모양이 이상해져요. 바깥 윤곽만 날카롭게 둬요.

  7. 중복 점 합치기메시 편집

    전체 선택 → M → By Distance
    같은 자리에 겹친 점을 하나로 합쳐요. 점이 안 붙으면 중복 점이 있는 거예요.

  8. 빨갛게 보이는 곳 정리메시 편집

    겹친 면의 한쪽을 내리거나 형태를 정리해요. Mirror 중앙을 뚫고 나간 점도 정리해요
    빨갛게(뒷면 표시) 보이는 곳은 면끼리 너무 가까워서 그래요.

  9. 겹친 뒷면 벌리기메시 편집

    Ctrl R 로 루프 컷 추가 → 선택 → Alt S
    뒤쪽 면끼리 바짝 붙어 겹치면 줄을 넣고 부풀려 벌려요.
    강의 42:45 쯤에 나오는 방법이에요.
강사의 팁
  • 왜 메꾸나요(강의 26:19): Unity에서 버추얼 캐릭터로 뽑을 때 뒷면이 없는 메시는 테두리(아웃라인)가 생기지 않아요. 아웃라인을 쓸 거면 반드시 입체로 만들어요.
  • 안쪽 면은 버추얼로 쓸 때 거의 안 보여요. 적당히 메꾸면 돼요.

윗머리 / 옆 덮는 머리

20:45~28:35

머리 위와 옆을 덮는 머리 조각이 뒷면까지 막혀 있어요.

  1. Plane 놓기메시 편집

    Plane 추가 → ` → Front 에서 위치를 잡아요
    윗머리도 평면에서 시작해요.

  2. Mirror 추가모디파이어

    Q → Mirror
    강사는 Quick Favorites에 Mirror 모디파이어를 등록해 두고 써요.
    Q 메뉴에 없으면 모디파이어 패널에서 Mirror를 추가하세요.

  3. Subdivision과 Auto Smooth모디파이어

    Ctrl 1 → 우클릭 → Shade Auto Smooth → 80
    둥글고 매끈하게 보이게 해요.

  4. 반 자르고 루프 컷 4개메시 편집

    반으로 잘라 한쪽을 지워요 → Ctrl R → 4개
    Mirror용으로 한쪽만 남기고, 휘게 할 줄을 넣어요.

  5. 위와 옆으로 휘게 배치이동·변형

    줄을 옮겨 머리 위와 옆을 덮도록 휘게 놓아요
    트윈테일에 가려 참조 형태가 안 보여서 예뻐 보이는 느낌으로 놓아요.
    강의 자막에 위치 수치가 없어요. 화면을 보고 맞추세요.

  6. 볼륨 주기이동·변형

    점 선택 → Alt S
    가운데를 부풀려요.
    과하면 되돌려요.

  7. 루프 컷으로 부드럽게메시 편집

    Ctrl R → 딱딱한 곳에 추가
    줄이 많아지면 곡면이 부드러워져요.

  8. 가장자리 Edge Crease메시 편집

    가장자리 엣지 선택 → Shift E → 1. 필요 없는 곳은 Shift E → 0
    윤곽을 날카롭게 남겨요.

  9. 뾰족한 곳 정리하고 메꾸기메시 편집

    뾰족한 점을 다듬어요 → 가장자리를 모아 붙여요 → F 로 뒷면 채우기
    앞에서 한 뒷면 메꾸기와 같아요.
    튀어나온 뿌리 쪽은 두피에 박아 넣어도 돼요.

  10. Subdivision 2로 올리기모디파이어

    이 조각의 Subdivision 모디파이어 → 레벨을 2 로

    트윈테일이 묶인 곳에서 아래로 떨어지는 모양을 잡아요.

  4. 굵기 조절하기커브

    점 선택 → Alt S (끝으로 갈수록 가늘게, 묶인 뿌리 쪽도 가늘게)
    점마다 Radius(굵기)를 바꿔요.
    점이 심하게 꺾이면 단면이 찌그러져요. 그럴 땐 Radius를 1로 두고 배치만 하세요. 굵기는 메시로 바꾼 뒤에 해도 돼요.

  5. 점 추가하기커브

    두 점 선택 → 우클릭 → Subdivide
    점이 모자라면 사이에 하나 더 넣어요.
    필요할 때만 해요.

  6. 옆에서도 휘게 하기커브

    ` → Right → 점을 옮겨 휘게 해요
    머리카락을 일자로 만들면 모델이 정적으로 보여요.

  7. 메시로 변환커브

    Convert to Mesh
    커브를 메시로 바꿔 세밀하게 편집해요.

  8. Mirror와 기본 세팅모디파이어

    Mirror 모디파이어 추가 → Ctrl A → Ctrl 1 → On Cage 켜기 → 우클릭 → Shade Auto Smooth → 80
    반대쪽 트윈테일을 만들고 다른 머리카락과 같은 설정으로 맞춰요.

  9. 빵빵하게 부풀리기이동·변형

    루프 선택 → Alt S, Proportional Editing 도 함께 써요
    트윈테일을 통통하게 만들어요.

  10. Subdivision 적용모디파이어

    Subdivision 모디파이어 → Apply
    나뉜 면을 진짜 점으로 굳혀서 더 부드러운 바탕을 만들어요.

  11. 반대쪽 지우고 다시 세팅모디파이어

    미러된 반대쪽 절반 삭제 → Mirror 모디파이어 추가 → Ctrl 1
    한쪽만 남기고 Mirror와 Subdivision을 다시 걸어 더 매끈하게 해요.

  12. 끝 마감하기메시 편집

    끝 루프 선택 → 뽑아요(강의 자막은 Alt E) → M → At Center
    뚫려 있는 끝을 한 점으로 모아 막아요.
    뽑는 단축키는 자막 표기 그대로라 정확하지 않을 수 있어요. 화면을 보고 맞추세요. 꼭 한 점으로 막지 않고 모아 두기만 해도 멀리서는 티가 안 나요.

트윈테일 삐친 가닥

71:15~80:30

트윈테일에 바깥으로 삐친 가닥 3개가 붙어 있어요.

  1. 면 복제해 떼기메시 편집

    트윈테일 메시에서 세로 3줄 정도의 면 선택 → Shift D → P
    본체에서 떼어 낸 조각이라 모양이 본체와 잘 어울려요.

  2. 바깥으로 삐치게이동·변형

    Proportional Editing 켜기 → 점을 옮겨 바깥으로 삐친 모양을 만들어요
    삐친 가닥이 있어야 머리가 풍성해 보여요.

  3. 본체보다 도드라지게이동·변형

    점 선택 → Alt S (뿌리 쪽은 더 빵실하게, 끝은 작게)
    본체에 묻히지 않고 눈에 띄게 해요.
    형태를 잡기 전에 볼륨부터 주세요.

  4. Edge Crease 주기메시 편집

    가장자리 엣지 선택 → Shift E → 1
    가닥 윤곽을 날카롭게 남겨요.

  5. 루프 컷과 볼륨메시 편집

    Ctrl R → 볼륨이 필요한 쪽에만 → Alt S
    부풀릴 줄을 넣고 볼륨을 줘요.
    반대쪽에 생긴 필요 없는 루프는 지워요.

  6. 뒷면 메꾸기메시 편집

    가장자리를 모아 붙여요 → F
    입체로 닫아야 아웃라인이 생겨요.
    뿌리 쪽이 본체에 파고드는 것은 무시해도 돼요. 흔들릴 일이 없는 부분이에요.

  7. 두 번째, 세 번째 가닥메시 편집

    같은 방법으로 두 번 더 만들어요. 방향과 모양만 다르게 하고, 필요 없는 부분은 삭제해요
    가닥이 여러 개여야 자연스러워요. 참조에 없어도 예뻐 보이게 볼륨을 더 줘요.
