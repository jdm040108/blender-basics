EP.03

귀, 치아, 혀, 몸 만들기

귀와 치아, 혀를 만들어 얼굴 텍스처에 함께 칠하고, 둥근 상자에서 몸통, 목, 팔, 다리, 발까지 만들어요.

강의 영상 열기
작업 환경 복귀귀 모델링귀 UV·색칠치아: 입을 얼마나 벌릴지 정하기윗니 모델링치아 UV·색칠아랫니와 배치혀몸통목팔다리와 발

작업 환경 복귀

0:00~1:00

EEVEE에서, Solid 화면인데도 칠한 텍스처 색이 보여요.

  1. EEVEE로 되돌리기파일·설정

    Render Properties → Render Engine → EEVEE
    Ep.2에서 베이크하느라 Cycles로 바뀌어 있어요. EEVEE가 부드럽고 빠르고, 최종 결과물도 EEVEE 기준이에요.

  2. Solid 셰이딩으로화면

    Viewport Shading 두 번째(Solid) 선택
    모델링할 때 가장 가볍고 형태가 잘 보이는 화면이에요.

  3. Solid에서 텍스처 색 보기화면

    셰이딩 옵션 드롭다운 → Color → Texture
    Solid 화면에서도 칠해 둔 텍스처 색이 보여요.

귀 모델링

1:02~6:40

안쪽이 파이고 귓바퀴가 있는 단순한 귀가 양쪽에 달려 있어요.

  1. Round Cube 꺼내기메시 편집

    Shift A → Mesh → Round Cube → S로 줄여 귀 위치에 놓기
    귀도 둥근 상자에서 시작해요.

  2. 납작하게 만들기이동·변형

    측면에서 볼 때 납작해지게 스케일
    귀는 얇은 판 모양이에요.

  3. 비스듬히 돌리기이동·변형

    R로 회전시켜 정면에서도 귀 모양이, 측면에서도 귀 옆면이 보이게 각도 주기
    귀는 머리 옆에 비스듬히 붙어 있어요.

  4. 트랜스폼 적용이동·변형

    Ctrl A → All Transforms
    오리진(기준점)이 3D 커서 자리인 월드 원점으로 가요. Mirror가 얼굴 중심을 기준으로 비추게 하려는 거예요.

  5. Mirror 추가모디파이어

    Q → Mirror
    반대쪽 귀가 생겨요.

  6. Subdivision 1 추가모디파이어

    Ctrl 1
    면을 잘게 나눠 귀가 부드러워져요.

  7. Shade Auto Smooth음영·노멀

    우클릭 → Shade Auto Smooth → 80°
    기본 30°는 날카롭게 보여요. 80°로 올려 매끈하게 해요.

  8. On Cage 켜고 다듬기모디파이어

    Subdivision의 삼각형(On Cage) 버튼 켜기 → 점을 옮겨 귀 모양으로 다듬기
    부드러워진 결과 위에서 직접 점을 잡고 고칠 수 있어요.

  9. 귀 앞면 Inset메시 편집

    귀 앞면 선택 → I
    앞면 안쪽에 테두리 한 줄을 만들어요. 귀 안쪽을 파기 위한 준비예요.

  10. 안쪽으로 넣기이동·변형

    비례 편집을 끄고 Alt S로 전체적으로 들어가게
    Alt S는 면이 바라보는 방향으로 밀거나 당겨요. 귀 안쪽이 오목해져요.

  11. 한 번 더 Inset메시 편집

    I → 가운데만 더 안으로 넣기
    가운데가 한 단 더 깊어져요.
    너무 얇아진 곳은 펴 줘요. 여기서 끝내도 돼요.

  12. 귓바퀴용 루프컷메시 편집

    Ctrl R로 루프컷 하나 → 위로 올리기
    귓바퀴(귀 가장자리 둥근 테)를 만들 선이에요.
    귓바퀴는 선택 사항이에요.

  13. 귓바퀴 두께 키우기메시 편집

    면 3개 선택 → Alt E → Extrude Faces Along Normals
    면이 바라보는 방향으로 뽑아내서 귓바퀴에 두께가 생겨요.

  14. 케이지 확인모디파이어

    Subdivision 모디파이어의 뷰포트 표시(모니터 아이콘) 끄기
    부드럽게 하기 전 실제 뼈대 모양(케이지)을 볼 수 있어요. 모양이 안 예쁜 원인을 찾을 때 써요.
    확인한 뒤에는 다시 켜요.

  15. 걸리는 엣지 Dissolve메시 편집

    걸리는 엣지 선택 → Ctrl X
    Dissolve는 면에 구멍을 내지 않고 선만 없애요. 연골이 귓바퀴와 자연스럽게 이어지게 해요.

  16. Smooth로 펴기메시 편집

    Smooth로 주변 펴기
    선을 없앤 자리를 고르게 해요.

  17. 육각형 면 정리메시 편집

    생긴 육각형 면에 엣지를 새로 잘라 넣어 정리
    꼭짓점이 5개 이상인 면(n-gon)은 음영이 깨지기 쉬워요.
    어떻게 잘랐는지는 강의 자막에 없어요. 화면을 보고 맞추세요.

  18. Subdivision 2로 올리기모디파이어

    귀의 Subdivision 레벨을 1에서 2로 → 음영이 강해진 곳은 Smooth
    귀가 딱딱해 보여서 한 단계 더 부드럽게 해요.
강사의 팁
  • 귓구멍과 귀 뒷면 디테일은 만들지 않아요.
  • 머리카락이 풍성한 디자인이면 귀는 어차피 안 보여요. 단순하게 만들어도 문제없어요.

귀 UV·색칠

6:42~10:45

귀가 피부색과 간단한 음영으로 칠해져 있고, 머리 오브젝트가 Head 컬렉션에 모여 있어요.

  1. 귀에 Seam 넣기UV

    한 군데만 엣지 선택 → 우클릭 → Mark Seam
    UV를 펴기 위해 자르는 선을 넣어요.
    어디를 자르는지는 자막이 '여기 부분만'이라고만 해요. 화면을 보고 맞추세요.

  2. 귀 UnwrapUV

    A → U → Unwrap → Face-img의 빈 곳에 배치
    귀를 얼굴과 같은 텍스처의 빈자리에 펴요.

  3. 귀 뒷면 UV 줄이기UV

    귀 뒷면 UV를 얇게 축소
    뒷면에는 중요한 색이 안 들어가서 공간을 아껴요.

  4. Face 머티리얼 할당재질·텍스처

    귀에 Face 머티리얼 할당
    얼굴과 같은 재질과 텍스처를 써요.
    안 하면 귀가 검게 보여요.

  5. 피부색 채우기페인트

    Texture Paint 또는 Image Editor(Paint 모드)에서 피부색으로 채우기
    귀 기본색이에요.
    경계 밖으로 삐져나가지 않게 해요.

  6. 귀 음영 칠하기페인트

    귓바퀴에 조금 밝은 색, 귀 안쪽은 어둡게 칠하기
    단순한 귀에 입체감을 줘요.

  7. 반투명하게 깔기페인트

    어두운 색 Strength 0.5 (기본 1) → 브러시를 크게 해서 칠하기
    명암 대비가 너무 셀 때 연하게 깔아 줘요. Strength는 색이 칠해지는 세기예요.
    반투명 칠은 한 획에 칠해야 해요. 겹치면 진해져요. 어울리지 않으면 지워요.

  8. 저장파일·설정

    파일을 저장해요
    여기까지의 작업을 저장해요.
    노트에 단축키는 적혀 있지 않아요.

  9. 이름을 Ear로파일·설정

    귀 오브젝트 이름을 Ear로 바꾸기
    나중에 찾기 쉽게 이름을 붙여요.

  10. Head 컬렉션으로 모으기파일·설정

    머리 관련 오브젝트를 한 컬렉션에 모으기 → 컬렉션 이름 Head
    머리 부품과 몸 부품을 구분해 둬요.
강사의 팁
  • 더 예쁜 컬러링은 좋은 참고 이미지를 보고 칠해요.

치아: 입을 얼마나 벌릴지 정하기

11:04~21:10

벌렸을 때의 입 크기가 화면에 메모돼 있어요.

  1. 벌린 입 크기 메모기타

    Annotate로 입을 벌렸을 때의 크기를 화면에 그려 두기
    치아와 혀 크기를 이 메모에 맞춰요. 크게 벌리는 캐릭터면 치아도 그만큼 커야 해요.
강사의 팁
  • 강사는 작은 입을 추천해요. 입이 크면 턱과 볼살이 같이 늘고 줄어야 해서 표정 만들기가 아주 어려워져요. 작은 입으로 먼저 연습하세요.

윗니 모델링

11:04~21:10

말굽 모양의 열린 껍데기 윗니가 있어요.

  1. 큐브 꺼내기메시 편집

    Shift A → Cube → S로 메모한 크기까지 줄이기
    치아도 상자에서 시작해요.

  2. 납작하게이동·변형

    S Z
    위아래로만 줄여서 납작한 판으로 만들어요.

  3. 루프컷 3개메시 편집

    Ctrl R → 루프컷 3개
    말굽 모양으로 만들 면을 나눠요.

  4. 절반 삭제메시 편집

    절반 선택 → 삭제
    Mirror로 대칭 작업을 하려고 반을 지워요.

  5. Mirror 추가모디파이어

    Q → Mirror
    반대쪽이 자동으로 따라와요.

  6. ㄷ자 블록 만들기메시 편집

    안쪽 면들 삭제 → F로 다시 메우기
    가운데가 빈 말굽(ㄷ자) 모양 블록이 돼요.
    정확히 어느 면인지는 강의 자막에 없어요. 화면을 보고 맞추세요.

  7. Subdivision 추가모디파이어

    Ctrl 1
    각진 블록이 부드러워져요.
    자막에는 'Ctrl E'로 적혀 있지만 맥락상 Ctrl+1(Subdivision)로 보여요. 화면을 보고 확인하세요.

  8. 모서리 엣지 Dissolve메시 편집

    모서리의 불필요한 엣지 두세 곳 선택 → Ctrl X
    모서리를 각지게 만드는 선을 없애요.

  9. 점 다시 잇기메시 편집

    버텍스 선택 → J
    J는 Connect Vertex Path예요. 고른 점 사이에 새 선을 그어 줘요. 둥근 아치가 되게 다시 이어요.

  10. 필요 없는 면과 윗면 삭제메시 편집

    필요 없는 면 삭제 → 윗면도 삭제
    윗니라서 위쪽은 안 보여요. 틀니처럼 열린 껍데기로 둬요.

  11. 루프컷으로 볼륨메시 편집

    Ctrl R로 루프컷 추가 → 볼륨 주기
    치아가 도톰해 보이게 해요.

  12. Shade Auto Smooth음영·노멀

    우클릭 → Shade Auto Smooth → 80°
    면이 매끈하게 보여요.

  13. 치아 형태 잡기이동·변형

    앞니 쪽은 납작하고 앞으로 몰리게, 어금니 쪽은 크게 다듬기
    뾰족한 송곳니를 만들 게 아니면 단순한 형태로 해요.

  14. Mirror Clipping 켜기모디파이어

    Mirror 모디파이어 → Clipping 체크
    꺼져 있으면 가운데가 안 예쁘게 벌어져요.

  15. 높이 평평하게 맞추기이동·변형

    들쭉날쭉한 줄 선택 → S Z 0 (아랫단, 안쪽, 윗단 각각)
    선택한 점들을 같은 높이로 맞춰요.

  16. 송곳니 만들기메시 편집

    원하는 자리의 면 하나 선택 → E로 아래로 → S로 줄이기
    뾰족한 송곳니가 생겨요.
    선택 사항이에요(16:04). 한쪽만 덧니로 하려면 대칭으로 만든 뒤 나중에 Mirror를 적용하고 한쪽만 고쳐요.

치아 UV·색칠

11:04~21:10

윗니가 흰색과 옅은 음영으로 칠해져 있어요.

  1. Face 머티리얼 할당재질·텍스처

    치아에 Face 머티리얼 할당
    치아도 얼굴과 같은 텍스처에 칠해요.

  2. 치아 UnwrapUV

    U → Unwrap → UV Editor에서 구석에 작게 배치
    치아는 작게 보이는 부분이라 UV도 작게 써요.

  3. Strength 1로 되돌리기페인트

    브러시 Strength를 1로
    귀에서 0.5로 낮춰 둔 값을 되돌려요.

  4. 흰색으로 칠하기페인트

    치아를 흰색으로 칠하기
    치아 기본색이에요.

  5. 치아 음영 넣기페인트

    팔레트의 흰자 그림자색으로 어금니 쪽, 치아 위쪽(잇몸 쪽), 안쪽 면을 어둡게 → 경계는 부드럽게
    음영 없이 하얗기만 하면 눈부신 이빨처럼 보여요.

아랫니와 배치

11:04~21:10

윗니와 아랫니가 Inner Mouth라는 한 오브젝트로 입속에 놓여 있어요.

  1. 윗니 복제이동·변형

    윗니 선택 → Shift D → 아래로 내리기
    아랫니는 윗니를 복제해서 만들어요.

  2. 위아래로 뒤집기이동·변형

    우클릭 → Mirror → Z Global
    위아래(Z) 방향으로 뒤집어서 아랫니가 돼요.

  3. 살짝 기울이기이동·변형

    치아를 살짝 돌려 기울이기
    치아는 살짝 기울어져 있어야 자연스러워요.

  4. 아랫니를 안쪽으로이동·변형

    아랫니를 윗니보다 뒤쪽으로 들어가게 배치
    위아래를 똑같이 놓으면 아랫니가 턱을 뚫어요.
    약간 부정교합처럼 보여도 뚫리지 않는 게 먼저예요.

  5. 높이와 앞뒤 조정이동·변형

    아랫니가 너무 높으면 낮추기 → 측면에서 보고 전체적으로 뒤로 빼기
    여러 표정에서도 치아가 얼굴 밖으로 삐져나오지 않게 해요.

  6. 윗니와 아랫니 합치기메시 편집

    윗니와 아랫니 선택 → Ctrl J
    한 오브젝트로 합쳐요.

  7. 뒤집힌 면 바로잡기음영·노멀

    빨갛게 보이면 Edit Mode에서 A → Alt N → Recalculate Outside
    면의 앞뒤 방향을 바깥쪽 기준으로 다시 계산해요. 합치면 면이 뒤집혀 보일 수 있어요.

  8. 이름을 Inner Mouth로파일·설정

    오브젝트 이름을 Inner Mouth로 바꾸기
    입속 부품이라는 뜻으로 이름을 붙여요.

혀

21:10~25:40

치열 안에 들어가는 혀가 Inner Mouth에 합쳐져 칠해져 있고, 텍스처가 파일로 저장돼 있어요.

  1. 큐브 꺼내기메시 편집

    Shift A → Cube
    혀도 상자에서 시작해요.

  2. Subdivision 추가모디파이어

    Ctrl 1
    상자가 둥글어져요.
    자막에는 'Ctrl E'로 적혀 있지만 맥락상 Ctrl+1(Subdivision)로 보여요. 화면을 보고 확인하세요.

  3. 뒤쪽 면 삭제메시 편집

    뒤쪽 면 하나 선택 → 삭제
    혀뿌리 쪽은 안 보여서 열어 둬요.

  4. 크기 줄이고 납작하게이동·변형

    S로 입속에 들어갈 크기까지 줄이기 → S Z로 납작하게
    혀 모양의 납작한 덩어리가 돼요.
    혀가 치열보다 크면 나중에 아주 곤란해요. 치열 안에 들어가는 크기로 해요.
