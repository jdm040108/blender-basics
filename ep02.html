EP.02

얼굴 모델링부터 색칠까지

둥근 상자에서 시작해 얼굴, 눈구멍, 입, 아이라인, 눈썹, 눈동자를 만들고, 텍스처 한 장에 UV를 펴서 색과 음영까지 칠해요.

강의 영상 열기
추가 에드온머리 베이스: Round Cube1차 적용 후 2차 Mirror+Subdivision눈구멍입구멍과 입 주변 루프눈 안쪽(흰자 공간)입 안쪽(구강)아이라인(윗 속눈썹 라인)삐죽 나온 속눈썹언더라인·쌍꺼풀·눈썹눈동자와 하이라이트텍스처 준비: 워크스페이스·머티리얼·이미지얼굴 UV얼굴 색칠얼굴 음영: 그라디언트 노드 → 베이크나머지 부위 UV와 색칠

추가 에드온

0:00~0:40, 1:01:27

Round Cube와 퀵 메뉴를 쓸 수 있고, 쉐이더에서 Ctrl+T가 동작해요.

  1. Extra Mesh Objects 설치애드온

    Edit → Preferences → Get Extensions → Extra Mesh Objects → Install
    Shift A → Mesh 메뉴에 Round Cube 같은 도형이 추가돼요. 머리를 이 도형으로 시작해요.

  2. QuickMenu 설치애드온

    Edit → Preferences → Get Extensions → QuickMenu → Install
    자주 쓰는 메뉴를 Q 퀵 메뉴(Quick Favorites)에 모아 두고 바로 꺼내 쓰려고 설치해요.

  3. Mirror를 퀵 메뉴에 등록모디파이어

    모디파이어 Add 메뉴 → Mirror 위에서 우클릭 → Add to Quick Favorites
    Mirror는 계속 쓰는 기능이라 퀵 메뉴에 넣어 둬요.
    노트에는 메뉴 이름이 'Add to Quick Favorites류'라고 적혀 있어요. 화면에서 비슷한 이름을 고르세요.

  4. 퀵 메뉴로 Mirror 추가모디파이어

    오브젝트 선택 → Q → Mirror
    등록해 둔 뒤에는 이렇게 한 번에 Mirror를 붙일 수 있어요.

  5. Origin to 3D Cursor 등록파일·설정

    Set Origin → Origin to 3D Cursor를 퀵 메뉴에 등록
    오브젝트의 기준점(오리진)을 3D 커서 자리로 옮기는 기능이에요. 눈동자 만들 때 써요.
    이 등록은 나중에(눈동자 구간에서) 해요.

  6. Node Wrangler 켜기애드온

    Ctrl T가 안 되면 Preferences → Add-ons → node 검색 → 체크
    쉐이더 노드 작업을 편하게 해 주는 애드온이에요. Ctrl T로 좌표 노드를 자동으로 붙여 줘요.
    쉐이더 작업 중(1:01:27)에 나와요. 자막에서 애드온 이름은 말하지 않아요. Node Wrangler로 보여요.

머리 베이스: Round Cube

0:40~6:20

정면과 측면 레퍼런스에 대략 맞는 둥근 머리 반쪽이 Mirror와 Subdivision이 걸린 채로 있어요.

  1. Round Cube 꺼내기메시 편집

    Shift A → Mesh → Round Cube → 왼쪽 아래 패널에서 Arc 6
    모서리가 둥근 상자예요. Arc는 둥근 정도이고 기본은 8, 1이면 그냥 사각형, 클수록 둥글어요.

  2. 파일 저장파일·설정

    파일을 저장해요
    작업을 잃지 않게 시작할 때 저장해 둬요.
    노트에 단축키는 적혀 있지 않아요.

  3. 선택이 안 되면 컬렉션 옮기기파일·설정

    새 오브젝트가 선택되지 않으면 img 컬렉션에서 다른 컬렉션으로 옮기기
    Ep.1에서 잠가 둔 img 컬렉션에 들어가면 선택이 안 돼요.
    선택이 잘 되면 건너뛰어요.

  4. Edit Mode로 전환화면

    Tab → Edit Mode
    점, 선, 면을 직접 고치는 모드예요.

  5. X-Ray 켜기화면

    Alt Z
    메시가 반투명해져서 뒤쪽에 가려진 점까지 한 번에 선택할 수 있어요.

  6. 왼쪽 절반 삭제메시 편집

    왼쪽 절반을 선택 → 삭제
    한쪽만 만들고 반대쪽은 Mirror로 자동으로 따라오게 하려고 반을 지워요.

  7. Mirror 추가모디파이어

    모디파이어 Add 메뉴 → Mirror (퀵 메뉴에 등록했다면 Q → Mirror)
    모디파이어는 원본을 건드리지 않고 효과를 덧붙이는 기능이에요. Mirror는 남은 반쪽을 거울처럼 반대편에 비춰 줘요.

  8. Clipping 체크모디파이어

    Mirror 모디파이어 → Clipping 체크
    가운데 선의 점이 반대편으로 넘어가지 않고 중심에 딱 붙어 있게 해요.
    Clipping을 켜지 않으면 다듬다가 중심선이 벌어져요.

  9. 머리 크기 맞추기이동·변형

    오브젝트를 S로 줄여 정면 레퍼런스의 머리 크기에 대략 맞추기
    밑그림의 머리와 비슷한 크기에서 시작해요.
    처음부터 완벽할 필요 없어요.

  10. 측면 확인화면

    ` → Right (강의는 넘패드 3)
    옆에서 봐도 크기가 맞는지 확인해요. 정면을 맞추면 측면은 대체로 맞아요.

  11. 비례 편집 켜기이동·변형

    Edit Mode에서 Proportional Editing 켜기
    비례 편집은 점 하나를 움직이면 주변 점도 부드럽게 따라오는 기능이에요. 둥근 형태를 덩어리째 다듬기 좋아요.

  12. 버텍스 움직여 형태 맞추기이동·변형

    버텍스를 G로 움직여 레퍼런스 윤곽에 맞추기
    밑그림의 머리 윤곽을 따라가게 해요.

  13. Mirror를 Edit Mode에서 보이게모디파이어

    Mirror 모디파이어의 삼각형(On Cage) 버튼 켜기
    Edit Mode에서 반대쪽이 안 보일 때 켜요. 미러된 결과를 보면서 고칠 수 있어요.

  14. Subdivision 1 추가모디파이어

    Ctrl 1
    Subdivision은 면을 잘게 나눠 둥글고 부드럽게 보이게 하는 모디파이어예요. 딱딱해 보이는 머리가 부드러워져요.

  15. Subdivision도 On Cage 켜기모디파이어

    Subdivision 모디파이어의 삼각형(On Cage) 버튼 켜기
    부드러워진 결과 모양 위에서 점을 직접 잡고 고칠 수 있어요.

  16. 얼굴형 배치이동·변형

    정면과 측면 레퍼런스에 맞춰 점을 옮기기. 코는 앞으로 당기고, 눈이 들어갈 영역의 면은 얼굴 옆쪽까지 밀어서 확보
    눈은 생각보다 얼굴 바깥쪽까지 차지해요. 미리 자리를 넓혀 둬요.
    측면에서 일부 루프가 한쪽으로 쏠려도 괜찮아요. 중간에 모양이 웃겨져도 차근차근 맞추면 돼요.

  17. 얼굴만 따로 보기화면

    /
    로컬 뷰예요. 선택한 것만 화면에 남겨서 레퍼런스 없이 모양을 확인해요. 한 번 더 누르면 돌아와요.

  18. Shade Auto Smooth음영·노멀

    우클릭 → Shade Auto Smooth → 각도 약 80°
    면이 각져 보이지 않고 매끈하게 보이게 해요. 각도보다 완만한 곳만 부드럽게 처리돼요.
강사의 팁
  • Round Cube에서 시작하는 이유: 얼굴의 옆면과 둥근 볼륨을 360도로 맞추는 게 가장 어려워서, 이미 볼륨이 있는 형태에서 출발해요. 자기만의 방법이 있으면 그걸 써도 돼요(5:04~5:50).

1차 적용 후 2차 Mirror+Subdivision

6:20~10:30

면이 더 촘촘해진 머리에 다시 Mirror와 Subdivision이 걸려 있고, 볼이 빵빵해요.

  1. Mirror와 Subdivision 적용모디파이어

    모디파이어 위에 마우스 커서를 두고 Ctrl A (Mirror, Subdivision 각각)
    적용하면 모디파이어 효과가 실제 메시로 굳어요. 면이 실제로 늘어나요.

  2. 다시 왼쪽 절반 삭제메시 편집

    Tab → Edit Mode → 왼쪽 절반 선택 → 삭제
    늘어난 면을 가지고 다시 반쪽 작업으로 돌아가요.

  3. Mirror 다시 추가모디파이어

    Q → Mirror → Clipping 체크
    다시 좌우 대칭으로 작업해요.
    중심선이 벌어지면 Clipping을 안 켠 거예요.

  4. Subdivision 다시 추가모디파이어

    Ctrl 1
    두 번 하는 이유는 눈구멍과 입구멍을 뚫을 만큼 면을 촘촘하게 만들기 위해서예요.

  5. Smooth 툴로 음영 펴기메시 편집

    Edit Mode의 Smooth 툴 선택 → 꺼져 보이는 곳을 고르고 노란 선을 당기기
    점들의 간격을 고르게 해서 울퉁불퉁한 음영을 펴 줘요. 당기면 부드럽게 펴지고 반대로 밀면 더 도드라져요.

  6. 볼륨 다듬기이동·변형

    비례 편집을 켠 채 점을 움직여 볼을 빵빵하게 만들기
    볼이 통통해야 귀여워요. 눈구멍을 뚫기 전에 볼륨부터 잡아요.
    한 곳만 살짝 내리면 그림자가 이상해져요. 주변을 같이 움직이고 다시 Smooth로 펴요.

  7. 여러 각도에서 확인화면

    ` 뷰 메뉴로 Front, Right 등을 오가며 확인 (강의는 넘패드)
    한 방향에서만 보면 다른 쪽이 어긋나요.
    이상한 음영은 보였을 때 바로 고쳐요.

눈구멍

10:30~16:15

레퍼런스의 흰자 윤곽을 따라 눈구멍이 뚫려 있어요.

  1. 눈 영역 면 선택선택

    레퍼런스의 눈(흰자 포함)에 해당하는 면들을 선택
    구멍을 낼 자리를 정해요.

  2. 삼지창 버텍스 정리메시 편집

    선이 세 갈래로 갈라지는 점이 걸리면 그 버텍스를 G X로 옮기기 → 울퉁불퉁해진 곳은 Smooth
    세 갈래로 갈라지는 점(폴)이 눈 영역 경계에 걸리면 구멍 모양이 지저분해져요. 옆으로 옮겨 피해요.

  3. Inset으로 살짝 줄이기메시 편집

    I → 살짝만 안으로
    Inset은 선택한 면 안쪽에 테두리 한 줄을 새로 만드는 기능이에요. 바로 지우지 않고 테두리부터 만들어요.

  4. LoopTools Circle메시 편집

    우클릭 → LoopTools → Circle → Influence를 낮게
    선택한 테두리를 원에 가깝게 정리해요. 네모에서 조금만 둥글게 해요.
    너무 둥글게 하면 삐뚤어져요. Influence 수치는 강의 자막에 없어요. 화면을 보고 맞추세요.

  5. 면 삭제로 구멍 내기메시 편집

    X → Faces
    선택한 면만 지워서 눈구멍이 생겨요.

  6. 테두리를 흰자 윤곽에 맞추기이동·변형

    구멍 테두리 버텍스를 레퍼런스 흰자 윤곽으로 이동. G G로 선을 따라 밀기
    G G는 Edge Slide예요. 점이 원래 있던 선을 따라서만 움직여서 면이 덜 어긋나요.

  7. 파묻힌 테두리 꺼내기이동·변형

    볼살에 눈 테두리가 파묻히면 테두리가 보이게 꺼내 주기
    테두리가 묻히면 볼살이 너무 앞에 나와 있는 거예요.

  8. 측면 어긋남 보정이동·변형

    정면 라인을 먼저 맞춘 뒤, 측면에서 어긋난 곳은 비례 편집을 켜고 G Y
    앞뒤 방향(Y)으로만 움직이면 정면에서 맞춘 모양이 흐트러지지 않아요.

  9. 따로 보며 점검화면

    / → 까맣게 보이는 좁은 면은 G G로 펴기
    면이 너무 좁으면 까만 그림자가 생겨요. 로컬 뷰에서 찾아서 펴 줘요.
    테두리 루프의 폭이 고를 필요는 없어요. 너무 까만 그림자만 조심해요.

  10. 눈꺼풀 밀어 넣기이동·변형

    눈꺼풀이 바깥으로 튀어나와 보이면 G Y로만 밀어 넣기
    다른 각도에서 봐도 예뻐야 해요.

입구멍과 입 주변 루프

16:15~20:50

입구멍이 뚫려 있고 입 둘레에 선이 여러 겹 둘러져 있어요.

  1. 입 영역 면 선택선택

    입을 크게 벌린 모습을 상상해서 그 크기만큼 면 선택
    나중에 표정을 만들 때 입이 크게 벌어져야 해요.
    레퍼런스에 그려진 다문 입 크기대로 뚫으면 안 돼요.

  2. Inset과 Boundary 조정메시 편집

    I → 중심에서 갈라지면 왼쪽 아래 패널의 Boundary 옵션 조정
    Mirror 중심선에서 테두리가 좌우로 갈라지지 않고 하나로 붙게 해요.
    자막은 'Boundary를 체크하면 붙는다'고 하지만 Ep.3에서는 반대로 설명해요. 눌러 보고 중심이 붙는 쪽으로 두세요.

  3. 면 삭제로 구멍 내기메시 편집

    X → Faces
    입구멍이 생겨요.

  4. LoopTools Relax메시 편집

    안쪽 테두리 선택 → 우클릭 → LoopTools → Relax
    테두리 점들의 간격을 고르게 풀어서 선을 매끄럽게 해요. Circle만큼 자주 써요.
    점이 적어서 반복 횟수는 1이나 3이나 차이가 없어요.

  5. 테두리 안쪽으로 익스트루드메시 편집

    E → S로 안쪽으로 줄이기
    익스트루드는 선택한 곳에서 새 면을 뽑아내는 기능이에요. 입 둘레에 선 한 겹이 새로 생겨요.

  6. 살짝 부풀리기이동·변형

    Alt S
    Shrink/Fatten이에요. 면이 바라보는 방향으로 부풀리거나 줄여요. 입술 둘레에 볼륨을 줘요.

  7. 선 정리 후 반복메시 편집

    G G로 정리 → 익스트루드, Alt S, 정리를 반복
    입 주변에 선(엣지 루프)을 여러 겹 만들어요. 루프가 여러 개여야 다양한 표정을 만들 수 있어요.

  8. 입 다물게 조정이동·변형

    벌어진 입 테두리를 모아서 다문 모양으로 조정
    구멍을 크게 뚫어서 입이 너무 벌어져 있어요. 기본 모양은 다문 입이에요.

  9. 입 위치 올리기이동·변형

    입 전체를 위쪽으로 이동 → 찌그러진 주변을 다시 정리
    귀여운 캐릭터는 입이 위쪽에 있어야 해요.

  10. 못생긴 그림자 펴기메시 편집

    그림자가 생긴 곳 선택 → Smooth. 안 잡히면 점을 직접 옮겨 볼륨 만들기
    입을 옮기면서 생긴 어색한 음영을 정리해요.

    구워진 이미지를 다른 이름으로 저장 → Face-img에 덮어쓰기
    음영이 들어간 그림이 얼굴 텍스처가 돼요.

  18. 노드 정리재질·텍스처

    그라디언트, 믹스, 에미션, 베이크 노드 삭제 → Image Texture(Face-img)의 Color → Material Output 직접 연결
    음영이 텍스처에 들어갔으니 처음의 단순한 직결 상태로 돌아가요.
강사의 팁
  • 얼굴 음영(앞머리 그림자와 머리통 음영)은 손으로 칠하지 않고 노드로 만든 뒤 텍스처에 구워요.
  • 원하는 효과는 노드로 만들어 굽거나 직접 붓으로 칠하거나, 편한 쪽으로 하면 돼요.

나머지 부위 UV와 색칠

1:06:30~1:17:46

흰자, 입속, 눈썹, 쌍꺼풀, 언더라인, 아이라인, 눈동자, 하이라이트까지 같은 텍스처에 색이 칠해져 있어요.

  1. 흰자 칠하기페인트

    Texture Paint에서 흰색으로 흰자 공간 칠하기
    눈 안쪽 공간을 흰자색으로 채워요.
    빠진 곳이 없게 꼼꼼히 칠해요.

  2. 흰자 위쪽 그림자페인트

    흰자 윗부분에 붓으로 부드러운 그림자 칠하기
    윗눈꺼풀 그림자가 생겨 눈이 깊어 보여요. 노드로 해도 되지만 간단해서 손으로 칠해요.

  3. 입속 UV 펴기UV

    입속 선택 → U → Unwrap (Angle Based)
    입속 면을 UV에 펴요.
    자막은 '앵글 베이스'라고 말해요.

  4. 입속 UV 배치UV

    UV Editor에서 빈자리에 배치 (다른 아일랜드와 띄우기)
    딱 붙이면 칠할 때 색이 서로 번져요.

  5. 입속 칠하기페인트

    팔레트에 적당한 갈색 추가 → 입속 칠하기
    입속 색은 팔레트에 없어서 새로 추가해요.

  6. 눈썹·쌍꺼풀·언더라인 UVUV

    그대로 펴서 UV 빈 곳에 겹치지 않게 배치
    가는 선 부품들도 같은 텍스처에 자리를 잡아 줘요.

  7. Face 머티리얼 할당재질·텍스처

    색이 안 칠해지면 그 오브젝트에 Face 머티리얼 할당
    Face 머티리얼이 없으면 색이 안 먹어요. 같은 Face-img 한 장을 함께 써요.

  8. 눈썹·쌍꺼풀·언더라인 칠하기페인트

    각각 색칠
    팔레트에 등록한 색으로 칠해요.

  9. 아이라인에 SeamUV

    아이라인 가운데 부분에 Seam 넣기 (엣지 선택 → 우클릭 → Mark Seam)
    Seam이 없으면 이상하게 펴져요. 잘라 주면 깔끔한 전개도가 나와요.

  10. 아이라인 UnwrapUV

    U → Unwrap
    직선에 가까운 전개도가 돼서 칠하기 쉬워요.

  11. 아이라인 안쪽 밝게페인트

    가로 루프컷을 기준으로 안쪽(아래) 절반에 밝은 색 칠하기
    아이라인 아래쪽이 밝아서 눈매가 살아나요.

  12. 직선으로 칠하기페인트

    Texture Paint 상단 Stroke → Stroke Method를 Space에서 Line으로
    드래그한 두 점 사이가 직선으로 칠해져요.

  13. Stroke Method 되돌리기페인트

    Stroke → Stroke Method를 다시 Space로
    직선 칠이 끝나면 보통 브러시로 돌아가요.

  14. 아이라인 경계 정리페인트

    딱딱한 모서리를 정리 → 경계가 애매하면 전체적으로 내려 주고 더 가늘게 깎기
    밝은 색과 어두운 색의 경계를 깔끔하게 해요.

  15. 눈동자에 Face 머티리얼재질·텍스처

    Eye 선택 → Face 머티리얼 할당
    눈동자도 같은 텍스처에 칠해요.

  16. 눈동자 UnwrapUV

    A → U → Unwrap
    눈동자를 UV에 펴요.

  17. 눈동자 UV 크게 배치UV

    UV Editor에서 다른 것보다 크게 배치
    눈이 가장 중요한 부분이라 그림을 크게 써서 선명하게 해요.

  18. 눈동자 칠하기페인트

    기본색으로 채우기 → 홍채의 파란 부분을 레퍼런스를 보고 따라 그리기
    삐뚤어진 곳은 UV 경계를 보면서 고쳐요.

  19. 하이라이트 칠하기페인트

    하이라이트를 흰색으로 칠하기
    앞에 떠 있는 조각이라 옆에서 봐도 입체감이 남아요.
강사의 팁
  • UV 빈 공간을 넉넉히 남겨요. 귀, 이빨, 혓바닥, 추가 홍조, 특수 표정용 눈을 같은 텍스처에 넣어야 해요.
