EP.13

블렌더에서 VRM 추출 + 유니티 최종 설정

블렌더에서 오브젝트를 합치고 정리해 VRM으로 내보내요. 유니티(Warudo SDK 프로젝트)에서 표정, 시선, 머리 흔들림, 콜라이더를 설정한 뒤 VRM 0.x로 다시 내보내요.

강의 영상 열기
A-1. 얼굴 오브젝트 합치기A-2. Hair 합치기, 탈부착 파츠A-3. Body, 의상A-4. 합친 뒤 본 연결 점검A-5. 컬렉션, 이름 정리B. 블렌더: VRM ExportC. 유니티 준비D. 유니티: VRM 메타 정보E. 유니티: BlendShape 클립 연결F. 유니티: 시선(Look At) 설정G. 유니티: 애니메이션으로 동작 테스트H. 유니티: 스프링본(머리 흔들림)I. 유니티: 콜라이더(머리카락이 얼굴을 뚫지 않게)J. 모델을 고쳐야 할 때K. 최종 확인과 VRM 0.x Export

A-1. 얼굴 오브젝트 합치기

0:00~2:20

Head, 눈, 아이라인, InnerMouth가 하나의 오브젝트가 되고 쉐이프 키도 합쳐져요.

  1. All Transforms 적용이동·변형

    Head, 눈, 아이라인, InnerMouth를 하나씩 선택 → Ctrl A → All Transforms
    오브젝트마다 원점(주황색 점) 위치가 다르면 합칠 때 문제가 생길 수 있어요. 적용하면 위치, 회전, 크기 값이 초기화되어 원점이 통일돼요.

  2. 얼굴 오브젝트 합치기메시 편집

    네 오브젝트를 전부 선택하고 Head를 마지막에 선택해 활성(노란 테두리)으로 → Ctrl J
    Ctrl+J는 선택한 오브젝트를 활성 오브젝트 하나로 합쳐요.
    합칠 수 있는 조건은 뼈(Armature)가 같고 MToon(아웃라인) 모디파이어가 같은 것이에요. 매테리얼은 서로 달라도 돼요.

  3. 쉐이프 키 확인쉐이프 키

    Data 탭 → Shape Keys 목록 확인
    같은 이름의 키끼리 합쳐졌는지 봐요.

  4. 합친 뒤 덩어리 격리(필요할 때)선택

    Edit Mode → 필요한 덩어리의 버텍스 선택 → Ctrl L → Shift H
    합친 뒤에 쉐이프 키를 더 만들 때 써요. Ctrl+L은 이어진 덩어리를 선택하고, Shift+H는 선택한 것 말고 전부 숨겨요.

  5. X축 대칭 켜고 작업메시 편집

    Edit Mode의 X축 대칭(Mirror X) 옵션을 켜고 작업 → 끝나면 반드시 꺼요
    Mirror 모디파이어가 이제 없어서, 한쪽을 고치면 반대쪽도 같이 움직이게 하려고 켜요.
    안 끄면 이후 다른 작업에서 문제가 생겨요.

A-2. Hair 합치기, 탈부착 파츠

2:20~5:00

머리카락이 Hair 하나로 합쳐지고, 양갈래는 Hair-Twintail로 따로 남아요.

  1. Hair 모디파이어 일반 Apply모디파이어

    Hair 조각 선택 → Modifiers 탭 → 모디파이어 위에서 Ctrl A (일반 Apply)
    Keep Shapekeys 메뉴는 쉐이프 키가 있는 오브젝트에서만 쓸 수 있어요. 쉐이프 키가 없는 Hair와 의상은 일반 Apply로 적용해요.
    Hair는 이전 편에서 원점을 통일해 둬서 적용 후 바로 합쳐요.

  2. Hair 합치기메시 편집

    양갈래를 뺀 머리 조각을 전부 선택하고 앞머리를 활성으로 → Ctrl J → 이름 Hair
    머리카락을 오브젝트 하나로 만들어요.
    Armature 모디파이어가 없는 머리 조각은 지금 추가하지 않아요. Armature가 있는 쪽에 합치면 자동으로 딸려 와요.

  3. 양갈래는 따로 두기기타

    양갈래는 합치지 않고 이름을 Hair-Twintail 로
    탈부착하고 싶은 파츠는 따로 둬요. 와루도 등에서 그 오브젝트만 숨기는 기능으로 켜고 끌 수 있어요.
    한쪽씩 따로 쓰려면 좌우를 별도 오브젝트로 둬요. 강사는 이후 L / R로 이름을 구분해요.

A-3. Body, 의상

5:00~6:35

Body의 모디파이어가 적용되고, 의상이 옷 한 벌 오브젝트 하나로 합쳐져요.

  1. Body 쉐이프 키 준비쉐이프 키

    Body 선택 → Shape Keys에서 Cloth-On 을 0으로 → Basis 를 선택
    Body에는 Cloth-On 쉐이프 키가 있어요. 0으로 두고 Basis가 선택된 상태에서 적용해야 해요.

  2. Body 모디파이어 적용애드온

    Object → Keep Shapekeys → Apply Chosen Modifiers → Mirror, Subdivision, Smooth by Angle 체크
    쉐이프 키를 지킨 채 모디파이어를 적용해요.

  3. 의상 모디파이어 일반 Apply모디파이어

    리본, 블라우스, 가디건, 바지, 신발 각각 → Modifiers 탭에서 Mirror, Smooth by Angle 등을 일반 Apply
    의상은 쉐이프 키가 없어서 일반 Apply로 돼요.

  4. 의상 원점 맞추기이동·변형

    원점이 다른 의상 선택 → Ctrl A
    합치기 전에 원점을 통일해요.

  5. 의상 합치기메시 편집

    의상을 전부 선택하고 아무 의상이나 활성으로 → Ctrl J
    옷 한 벌(셋업)이 오브젝트 하나가 돼요.

A-4. 합친 뒤 본 연결 점검

6:35~9:28

Head 본을 돌리면 얼굴과 머리카락이 전부 따라와요.

  1. Pose Mode에서 확인리깅

    Armature를 보이게 켬 → Pose Mode → Head 본을 돌려 봐요
    합친 메쉬가 뼈를 잘 따라오는지 확인해요.

  2. Armature Object 다시 지정모디파이어

    Hair 선택 → Modifiers 탭 → Armature 모디파이어의 Object 칸에 아마추어를 다시 지정
    Hair가 안 따라오면 모디파이어가 뼈대를 못 찾고 있는 거예요.

  3. Hair-Root 부모를 Head로리깅

    Hair-Root 본 선택 → Bone 탭 → Parent를 Head 로
    Hair-Root 본이 Head에 연결돼 있지 않아서 머리를 돌려도 안 따라왔어요.

  4. 안테나 본 부모 지정리깅

    안테나(더듬이 머리) 첫 본 선택 → Bone 탭 → Parent를 Hair-Root 로
    더듬이 머리도 머리 뿌리를 따라가게 해요.

  5. 웨이트 없는 머리에 1웨이트

    Vertex Groups에서 Hair-Root 선택 → Edit Mode에서 그 머리카락을 전부 선택 → Weight 1 → Assign
    그래도 안 따라오는 머리 메쉬는 웨이트(뼈를 따르는 정도)가 없는 거예요.

  6. 본 돌려 보기리깅

    Pivot Point를 Individual Origins 로 → 본 선택 → R X X, R Y Y, 또는 R
    축 키를 두 번 누르면 그 본 자신의 축 방향으로 돌아요. 머리카락 본이 잘 움직이는지 봐요.
    머리가 찰랑거리는 물리는 유니티에서 설정해요. 블렌더에서는 뼈만 심으면 돼요.

A-5. 컬렉션, 이름 정리

9:28~12:08

모든 오브젝트가 한 컬렉션에 모이고, 이름에 접두어가 붙고, 전부 Armature의 자식이 돼요.

  1. 컬렉션 하나로 모으기파일·설정

    Outliner에서 Armature, Cloth, Body, Face, Hair를 하나의 컬렉션(예: SD-Character)으로 옮기고 예전 컬렉션(Cloth/Hair/Head)은 삭제
    내보낼 것들을 한곳에 모아 정리해요.

  2. 놓친 머리 조각 합치기메시 편집

    놓친 머리 조각(Plane)을 Hair에 합쳐요
    남은 조각이 따로 나가지 않게 해요.

  3. 이름에 접두어 붙이기파일·설정

    오브젝트 선택 → F2 → SD-Body, SD-Face, SD-Hair, SD-Cloth 처럼 접두어를 붙여요. 트윈테일은 L / R로 구분
    오브젝트 이름이 Body, Cloth처럼 본 이름과 같거나 비슷하면 유니티에서 인식을 못 할 확률이 높아요.
    추출 전에 꼭 해요. 이유는 강사도 모른다고 해요.

  4. SD-Face를 Armature 자식으로리깅

    SD-Face 선택 → Armature를 마지막에 선택해 활성으로 → Ctrl P → With Empty Groups
    모든 메쉬가 Armature의 자식이어야 Armature만 움직여도 전부 따라와요.
    자막은 '빈 그룹'이라고만 해요. With Empty Groups로 보여요. 화면을 보고 확인하세요.

  5. 햇빛 숨기기화면

    Outliner에서 햇빛(라이트)을 숨겨요
    내보낼 때 필요 없어요.

HairSD-Hair양갈래 제외

B. 블렌더: VRM Export

12:08~15:11

본 매핑을 마치고 SD.vrm 파일이 저장돼요.

  1. 내보낼 것 선택 후 Export파일·설정

    Armature와 메쉬들을 선택 → File → Export → VRM
    VRM은 버추얼 아바타용 파일 형식이에요.

  2. 팔다리 본은 Left부터리깅

    본 매핑 창에서 Left 쪽 UpperArm, LowerArm, Hand, UpperLeg, LowerLeg, Foot 을 먼저 채우고, 남은 것 중에서 Right를 골라요
    휴머노이드 본 매핑은 내 뼈가 사람 몸의 어느 부위인지 알려 주는 표예요. Right 항목은 목록 아래쪽에 있어 찾기 번거로워서 Left부터 채우면 쉬워요.
    본 이름을 규칙대로 지어 놨으면 대부분 자동으로 채워져요. 좌우가 나뉜 팔다리는 특히 조심하세요. 여기서 실수하면 안 돼요.

  3. 눈, 어깨, 발가락 본 넣기리깅

    Eye 본을 넣고, Shoulder(왼쪽부터)와 Toes를 넣어요. Jaw와 UpperChest 칸은 비워요
    만든 본만 넣어요. 턱(Jaw)과 UpperChest는 본을 안 만들었으니 비워 둬요.

  4. 손가락 본 넣기리깅

    엄지, 검지, 중지, 약지, 새끼를 순서대로 넣어요
    첫 마디를 제대로 고르면 나머지 마디는 알아서 이어져요.
    강사는 엄지 칸에 Middle을 넣는 실수를 했다가 고쳤어요. 한 번 해 두고 저장하면 다음부터 그대로 유지돼요.

  5. 저장 창에서 내보내기파일·설정

    OK → 저장 창에서 파일명을 캐릭터 이름으로(예: SD.vrm) → Export Only Selections 체크 → 저장
    Export Only Selections를 켜면 선택한 것만 나가요.
    시간이 조금 걸려요. 탐색기에서 아이콘이 흰 종이로 보여도 정상이에요.

C. 유니티 준비

15:11~19:30

Warudo SDK 프로젝트가 열리고 SD.vrm이 씬에 올라와요.

  1. 설치 안내 페이지 열기Unity

    영상 설명란의 Warudo Docs 'Unity & Warudo SDK 설치' 페이지(docs.warudo.app/docs/modding/…)를 열어요
    이 페이지 순서대로 설치해요.

  2. Unity Hub 설치, 로그인Unity

    Unity Hub를 설치하고 로그인
    유니티 에디터와 프로젝트를 관리하는 프로그램이에요.

  3. Unity Editor 2021.3.18 설치Unity

    Unity Editor 2021.3.18 을 내려받음 → Unity Hub → Installs → Locate 로 등록
    와루도 SDK가 이 버전에 맞춰져 있어요.
    자막에는 2021.3.18까지만 나와요. 정확한 패치 접미사는 Warudo Docs 페이지에서 확인하세요.

  4. 전용 프로젝트 템플릿 받기Unity

    와루도가 제공하는 Warudo SDK 0.12.0 Modding Project 를 내려받아 용량 넉넉한 드라이브에 압축 해제
    VRM 추출과 와루도용 추출 기능이 이미 다 들어 있는 프로젝트예요.

  5. 프로젝트 열기Unity

    Unity Hub → Add → Add project from disk → 압축 푼 폴더 선택 → 열기
    Hub에 프로젝트를 등록하고 열어요.
    첫 로딩이 매우 길어요.

  6. 캐릭터 폴더 만들기Unity

    Project 창에서 Assets 우클릭 → Create → Folder → 이름 Character → 그 안에 캐릭터 이름 폴더 SD
    캐릭터 파일을 넣을 자리를 만들어요.

  7. VRM 넣기Unity

    SD.vrm 을 SD 폴더로 드래그
    유니티가 VRM을 읽어 프리팹(재사용할 수 있는 묶음)을 만들어요.
    임포트에 시간이 걸려요.

  8. 프리팹을 씬에 올리기Unity

    생긴 프리팹을 Hierarchy로 드래그
    씬에 올려야 설정을 만질 수 있어요.

  9. 뷰 회전Unity

    Scene 뷰에서 Alt + 좌클릭 드래그
    화면을 돌려 캐릭터를 여러 방향에서 봐요.

  10. 원근/직교 전환Unity

    Scene 뷰 기즈모의 Persp 글자를 클릭
    원근감 있는 화면과 없는 화면을 오가요.

D. 유니티: VRM 메타 정보

19:30~23:39

썸네일, 이름, 버전, 작가 같은 VRM 기본 정보가 채워져요.

  1. 캐릭터 선택Unity

    Hierarchy에서 캐릭터(SD) 클릭 → Inspector 확인
    처음에는 정보가 비어 있어요.

  2. 카메라 돌리기Unity

    Main Camera 선택 → Inspector에서 Rotation Y를 180 으로 → 캐릭터에 가깝게 배치
    썸네일을 찍으려고 카메라가 캐릭터 정면을 보게 해요. SD라 작아서 가까이 둬요.

  3. 조명 조정Unity

    조명 선택 → Position -0.51 / 1 / 1.5, Rotation 8 / -180 / 0
    얼굴이 밝게 보이게 해요.
    강사 값이에요. 자유롭게 바꿔도 출력에 영향이 없어요.

  4. 썸네일 찍기Unity

    Game 뷰에 캐릭터가 잘 잡혔는지 확인 → Inspector의 스크린샷 버튼 → Assets/Character/SD 폴더에 저장
    저장하면 썸네일 칸에 자동으로 들어가요.

  5. 메타 정보 입력Unity

    Inspector에서 Title에 SD, 버전에 0.00, 작가 이름 입력. 배포할 거면 연락처 이메일도 입력
    VRM 파일에 들어가는 기본 정보예요.
    사용 허가(폭력/성적 표현 등)는 기본값(불허)으로 둬요.

E. 유니티: BlendShape 클립 연결

23:39~25:54

VRM 표정 클립마다 SD-Face의 쉐이프 키가 연결돼요.

  1. BlendShape 편집 창 열기Unity

    Inspector의 BlendShape(BlendShapeAvatar 에셋)를 더블클릭
    표정 클립을 편집하는 창이 열려요. 아래쪽 미리보기 영역으로 확인해요.
    기본 클립 버튼을 눌러도 처음에는 아무 표정도 안 나와요.

  2. 립싱크 클립 연결Unity

    클립 A 선택 → SD-Face 의 쉐이프 키 A 슬라이더를 올려 저장. I, U, E, O, Blink 도 같은 이름끼리 똑같이
    클립은 '이 표정일 때 어떤 쉐이프 키를 얼마나 올릴지'를 적어 두는 칸이에요.

  3. 표정 슬롯에 넣기Unity

    Joy 클립에 Happy 슬라이더, Angry 클립에 Angry 슬라이더를 올려요. 놀람(Surprise)은 남는 슬롯에 넣어요
    Joy, Angry, Sorrow, Fun은 VRM 기본 표정 슬롯이에요. 같은 이름의 표정을 안 만들었어도 슬롯에 원하는 표정을 넣으면 돼요.
    놀람을 어느 슬롯에 넣었는지는 자막으로 확실하지 않아요. 화면상 Sorrow나 Fun 중 하나로 보여요. 화면을 보고 맞추세요.

  4. Is Binary 체크Unity

    Angry처럼 즉시 바뀌었으면 하는 클립에서 Is Binary 체크
    체크하면 표정이 0 아니면 1로 확 바뀌어요. 체크하지 않으면 스르륵 바뀌어요.

  5. 나머지 슬롯 비워 두기Unity

    넣을 게 없는 슬롯과 Blink_L / Blink_R, LookLeft / LookRight 등은 건너뛰어요
    립싱크 캐릭터에는 필요 없어요. 데이터를 안 넣은 클립은 값을 올려도 아무 일도 안 생겨요.

F. 유니티: 시선(Look At) 설정

25:54~33:10

눈이 타깃을 따라 움직이고, 눈알이 뒤집히지 않게 각도 범위가 맞춰져요.

  1. Inspector 잠그기Unity

    Inspector 오른쪽 위 자물쇠 클릭
    다른 것을 클릭해도 Inspector가 캐릭터를 계속 보여 줘요. 본을 드래그해 넣을 때 필요해요.

  2. Head 본 넣기Unity

    Hierarchy에서 Hips → Spine → Chest → Neck → Head 본을 찾아 VRM Look At Head 의 Head 칸으로 드래그
    시선 계산의 기준이 되는 머리 본을 알려 줘요. 처음에는 칸이 비어 있어요.

  3. 타깃 큐브 만들기Unity

    Hierarchy 빈 곳 우클릭 → 3D Object → Cube → Position 0, 0, 0 / Scale 0.1 → 너무 커서 0.01 로 → 미간 앞에 배치
    눈이 따라갈 임시 목표물이에요.

  4. Target에 큐브 넣기Unity

    큐브를 VRM Look At Head 의 Target 칸으로 드래그
    눈이 이 큐브를 바라보게 돼요.

  5. Play 하고 큐브 움직이기Unity

    Play(재생) 버튼 → Scene 탭으로 가서 큐브를 움직여요
    재생해야 동작해요. 큐브를 움직이면 눈이 따라와요.

  6. Degree Mapping 조정Unity

    VRM Look At Bone Applyer 의 Degree Mapping을 펼쳐 커브의 Y Range/Degree 값 조정: Horizontal Outer 12, Horizontal Inner 13, Vertical Up 18, Vertical Down 5
    눈이 최대로 돌아가는 각도예요. 값이 너무 크면 눈알이 바깥으로 나가거나 뒤집혀 무서워져요.
    기본값은 Outer 10, Up 20, Down 10이에요. Down 기본값은 너무 아래를 봐요.

  7. Copy ComponentUnity

    재생 중에 그 컴포넌트 오른쪽 ⋮ → Copy Component
    재생 중 바꾼 값은 재생을 풀면 초기화돼요. 그래서 먼저 복사해 둬요.

  8. 정지 후 PasteUnity

    재생 정지 → 같은 컴포넌트 ⋮ → Paste Component Values
    복사해 둔 값을 붙여 넣어 남겨요.

  9. 타깃 정리Unity

    VRM Look At Head 의 Target을 None으로 → 큐브 삭제
    임시 목표물은 이제 필요 없어요.
    또 쓸 거면 삭제하지 말고 체크박스로 비활성화해요.

  10. 매테리얼 위치 확인Unity

    Project 창 → Assets/Character/SD/SD.Materials 폴더
    매테리얼이 MToon으로 넘어와 있어요. 더 고치려면 여기서 수정해요.

G. 유니티: 애니메이션으로 동작 테스트

33:40~41:54

Mixamo 테스트 동작을 캐릭터에 걸어 재생해 볼 수 있어요.

  1. Mixamo 테스트 팩 받기Unity

    mixamo.com (무료 가입) → test 검색 → Free Test Pack → Download: Format FBX Binary, Skin은 No Character(Without Skin), FPS 30 그대로
    동작만 들어 있는 테스트용 애니메이션 묶음이에요.

  2. Assets에 넣기Unity

    압축을 풀어 폴더째 프로젝트 Assets 로 드래그
    파일 11개가 들어와요.

  3. Humanoid로 바꾸기Unity

    FBX 선택 → Inspector Rig 탭 → Animation Type을 Generic에서 Humanoid 로 → Apply
    사람형 뼈대로 인식시켜야 내 캐릭터에 동작을 입힐 수 있어요.
    Humanoid로 바꾸지 않으면 미리보기가 안 떠요. 11개 모두 반복해요.

  4. Loop Time 체크Unity

    Inspector Animation 탭 → Loop Time 체크 → Apply
    동작이 끝나도 계속 반복돼요.
    11개 모두 반복해요.

  5. Animator Controller 만들기Unity

    Assets/Character/SD 에서 우클릭 → Create → Animator Controller → 이름 SD-AnimationController → 더블클릭으로 Animator 창 열기
    어떤 동작을 재생할지 정하는 파일이에요.

  6. 클립 이름 바꾸기Unity

    FBX를 펼침(▶) → Animation 탭(Edit)에서 클립 이름을 파일 이름으로 → Apply
    클립 이름이 전부 mixamo.com 이라 구분이 안 돼요.
    Apply가 안 눌리면 Loop Pose 같은 것을 하나 체크했다가 적용하세요. 이름이 안 바뀐 것은 테스트용이라 그냥 빼요.

  7. 클립 배치Unity

    클립들을 Animator 창으로 드래그
    컨트롤러에 동작이 등록돼요.

  8. Controller 연결 후 PlayUnity

    SD-AnimationController 를 캐릭터 Inspector의 Animator → Controller (None) 칸으로 드래그 → Play
    캐릭터가 동작을 재생해요.

  9. 다른 동작 보기Unity

    Animator 창에서 해당 상태 우클릭 → 두 번째 항목 Set as Layer Default State
    기본으로 재생할 동작을 바꿔요.

H. 유니티: 스프링본(머리 흔들림)

41:54~44:51

머리카락 본이 스프링본에 등록되어 움직일 때 찰랑거려요.

  1. Root Bones에 Hair-Root 등록Unity

    캐릭터 아래 secondary 오브젝트 선택 → VRM Spring Bone 컴포넌트 → Hierarchy의 Head 아래 Hair-Root 본을 Root Bones 글자 위로 드래그
    스프링본은 뼈를 물리로 흔들어 주는 기능이에요. 추가로 넣은 머리카락 본은 직접 등록해야 흔들려요.
    등록되면 노란 기즈모가 보여요. Head, Neck 같은 휴머노이드 본은 VRM이 알아서 처리해요.

  2. Play 중 값 조정Unity

    Play 상태에서 값을 드래그하며 조정: 힘 관련 값 0.7, Drag Force 0.3
    Drag Force가 크면 천천히 느리게, 작으면 빨리 돌아와요.
    0.7을 넣는 칸을 자막은 '이 값'이라고만 해요. Stiffness Force로 보이지만 확실하지 않아요. 그 외 추천 값은 화면으로만 나와요. 화면을 보고 맞추세요.

  3. 격한 모션에서 점검Unity

    백플립 같은 격한 모션을 재생해 보고 앞머리가 뒤집힐 정도면 값을 조절해 덜 움직이게
    심한 동작에서도 머리가 망가지지 않게 해요.

  4. Copy → 정지 → PasteUnity

    VRM Spring Bone 의 ⋮ → Copy Component → 재생 정지 → secondary 의 VRM Spring Bone ⋮ → Paste Component Values
    재생 중 바꾼 값은 정지하면 사라져서 복사해 붙여 넣어요.

I. 유니티: 콜라이더(머리카락이 얼굴을 뚫지 않게)

44:51~48:48

머리 콜라이더가 등록되어 머리카락이 얼굴을 뚫지 않고, 설정이 프리팹에 저장돼요.

  1. HeadCollider 만들기Unity

    Hierarchy에서 Head 본 우클릭 → Create Empty → 이름 HeadCollider
    머리를 따라다니는 빈 오브젝트를 만들어 거기에 충돌 영역을 달아요.

  2. Collider Group 추가Unity

    Inspector → Add Component → collider 검색 → VRM Spring Bone Collider Group
    콜라이더는 머리카락이 못 들어오게 막는 보이지 않는 공이에요. 핫핑크 구가 생겨요.

  3. Radius, Offset 조정Unity

    Colliders → Element 0 을 펼침 → Radius(반지름)와 Offset으로 얼굴을 적당히 감싸게 조정
    공이 얼굴 크기와 위치에 맞아야 해요.
    옆에서 보며 앞쪽으로 옮기고, 소수점을 직접 입력해 미세 조정해요. 수치는 자막에 없어요. 화면을 보고 맞추세요.

  4. Collider Groups에 등록Unity

    secondary 의 VRM Spring Bone → Collider Groups 를 펼침 → HeadCollider 를 드래그
    스프링본이 이 콜라이더를 피해 가게 돼요.

  5. Play로 확인Unity

    Play → 고개 돌리는 모션으로 확인
    머리카락이 얼굴을 뚫지 않는지 봐요.
    차이가 안 보이면 반지름을 일부러 키워 머리카락이 밀려나는지 확인하세요.

  6. Overrides → Apply AllUnity

    재생을 풀고 캐릭터(SD) 선택 → Inspector 상단 Overrides → Apply All
    씬에서 바꾼 설정을 프리팹에 저장해요.
강사의 팁
  • 긴 머리 캐릭터라면 몸 관절 곳곳에 콜라이더를 만들어 같은 방식으로 등록해요.

J. 모델을 고쳐야 할 때

48:54~51:46

블렌더에서 고친 모델을 다시 가져와서, 앞에서 한 유니티 설정을 그대로 옮겨요.

    같은 이름으로 같은 폴더에 넣으면 겹쳐서 안 돼요.

  3. 두 프리팹 씬에 꺼내기Unity

    수정 전, 수정 후 프리팹을 둘 다 Hierarchy로 드래그 → 하나는 Hips를 옆으로 옮겨요
    둘이 겹쳐 있어서 하나를 옆으로 빼요.

    수정 전 것의 컴포넌트 ⋮ → Copy → 수정 후 것의 같은 컴포넌트 ⋮ → Paste

  5. Root Bones 다시 지정Unity

    수정 후 캐릭터의 secondary → VRM Spring Bone → Root Bones 에 수정 후 캐릭터의 Hair-Root 를 다시 넣어요
    secondary(VRM Spring Bone)를 그대로 복사하면 Root Bones가 수정 전 캐릭터의 Hair-Root를 가리켜요.
    잊기 쉬운 주의점이에요.
