EP.08

옷 리깅: 데이터 전송(Data Transfer)으로 간단하게

몸 메시를 복제하고 부풀려 블라우스, 가디건, 바지, 신발과 양말을 만들고 리본은 큐브로 만들어요. 그다음 Data Transfer 모디파이어로 몸의 웨이트를 옷에 한 번에 옮기고, 머리카락 아마추어를 몸 아마추어에 합쳐요.

강의 영상 열기
시작 전 정리의상 구성과 설계 원칙옷 만드는 기본 방식: 몸 메시 복제 → 분리 → 부풀리기블라우스리본 (큐브에서 새로 모델링)가디건바지신발 + 양말 (한 메시)아웃라인 관련 주의옷 웨이트: Data Transfer 모디파이어 (리본)옷 웨이트: Data Transfer 모디파이어 (블라우스·가디건·바지·신발)전송 후 웨이트 손보기몸이 옷을 뚫을 때: Shape Key Cloth-On안쪽 옷이 바깥 옷을 뚫을 때: 안 보이는 면 삭제Hair 아마추어를 Body 아마추어에 합치기옷 머티리얼 준비

시작 전 정리

0:00~0:52

머리카락 포즈가 원래대로 돌아가고 작업 화면이 정리돼 있어요.

  1. 머리 포즈 초기화리깅

    Hair 아마추어 Pose Mode → 본 전체 선택 → 기본 포즈로 되돌리기
    지난 편에서 확인하느라 돌려 둔 본을 원래 자세로 돌려요.
    되돌리는 단축키는 강의 자막에 없어요. 화면을 보고 따라 하세요.

  2. 아웃라인 표시 다시 켜기모디파이어

    머리카락 메시의 MToon 아웃라인 모디파이어 → 뷰포트 표시(모니터 아이콘) 켜기
    지난 편에서 리깅하느라 꺼 둔 아웃라인을 다시 보이게 해요.
    꼭 해야 하는 건 아니에요.

  3. Sun 숨기기화면

    Sun 라이트의 눈 아이콘 끄기
    작업 중에는 조명이 필요 없어요.

의상 구성과 설계 원칙

0:52~3:54

어떤 옷을 만들지와, 왜 바지를 고르는지 알게 돼요.

강사의 팁
  • 만들 옷: 가운데 리본, 둥근 카라 블라우스, 앞이 열린 긴 가디건(오버핏), 끝단이 말려 올라간 짧은 바지, 양말과 작은 신발.
  • SD 캐릭터라서 신발은 디테일이 필요 없어요.
  • 치마를 만들 거면 미니스커트로 하세요. 긴 치마는 가닥마다 펄럭이는 본을 따로 심어야 해서 리깅이 훨씬 어려워져요.
  • 바지는 다리 본의 웨이트만 따오면 끝나요. 초보자용 강의라서 바지를 골랐어요.

옷 만드는 기본 방식: 몸 메시 복제 → 분리 → 부풀리기

몸에서 떼어 낸 면을 부풀려 옷의 바탕을 만드는 방법을 알게 돼요.

  1. 옷 영역 면 선택선택

    Body 메시 Edit Mode → 옷이 덮을 영역의 면 선택
    몸의 면을 그대로 본떠 옷을 만들 거예요.

  2. 복제메시 편집

    Shift D
    선택한 면을 복제해요. 몸은 그대로 두고 복사본으로 옷을 만들어요.

  3. 별도 오브젝트로 분리메시 편집

    P → Selection
    Separate 기능이에요. 복제한 면이 몸과 다른 오브젝트가 돼요.

  4. Body 머티리얼 제거재질·텍스처

    새 오브젝트의 머티리얼 슬롯에서 Body 머티리얼 제거
    옷은 따로 칠할 것이라 몸의 재질은 빼요.

  5. Proportional 끄기이동·변형

    Proportional Editing 끄기
    선택한 것 주변까지 함께 움직이는 기능이에요. 켜져 있으면 고르게 부풀지 않아요.

  6. 살짝 부풀리기이동·변형

    Edit Mode에서 전체 선택 → Alt S → Shift 를 누른 채 마우스를 움직여 미세 조절
    Alt+S는 Shrink/Fatten이에요. 면이 향한 방향으로 부풀려서 몸보다 조금 큰 옷이 돼요.

  7. 따라온 Seam 지우기UV

    빨간 Seam 선 전부 선택 → Clear Seam
    몸에서 따라온 UV 절개선은 필요 없어요. 옷 UV는 다음 편에서 새로 펴요.
강사의 팁
  • 이렇게 만들면 몸의 버텍스 그룹(웨이트)과 모디파이어(Mirror, Subdivision 등)가 그대로 따라와서 포즈를 잡으면 대체로 잘 따라와요.
  • Solidify, Shrinkwrap 모디파이어는 쓰지 않아요. 두께는 Alt+S와 끝단을 안쪽으로 말아 막는 방식으로 표현해요.
  • 겹치는 순서는 안에서 밖으로 Body, 블라우스, 그리고 바지(블라우스보다 조금 크게)와 가디건(블라우스보다 두툼하게)이에요.
  • 중간 크기를 찾기 어려우면 바깥 옷을 키우지 말고 안쪽 옷(블라우스)을 줄이세요. 어차피 안 보여요.

블라우스

3:54~8:45

둥근 카라가 달린 블라우스가 만들어져 있어요.

  1. 상체 복제·분리메시 편집

    Body Edit Mode → 블라우스 영역 면 선택 → Shift D → P → Selection
    상체 면을 떼어 블라우스의 바탕으로 써요.

  2. 살짝 키우기이동·변형

    전체 선택 → Alt S
    몸보다 조금 크게 부풀려요. 이 상태는 민소매 속옷 같은 모양이에요.

  3. 스냅 끄고 Pivot 바꾸기이동·변형

    스냅(자석) 끄기 → Pivot 을 Median Point 로
    점이 엉뚱한 곳에 달라붙지 않게 하고, 선택한 것의 가운데를 기준으로 움직이게 해요.

  4. 넥라인 둥글게 내리기메시 편집

    목선의 점·엣지 선택 → G G 또는 G 로 아래로 내리기. 뒷목도 똑같이
    G를 두 번 누르면 Edge Slide예요. 점이 기존 선을 따라 미끄러져서 모양이 덜 망가져요.

  5. 넥라인 다듬기메시 편집

    너무 네모나면 G X, G Y 로 다듬기. 몸이 뚫고 나오면 G Z 로 조정
    축 하나로만 움직여서 목선을 둥글게 정리해요.

  6. 카라 뽑기메시 편집

    넥라인 엣지 루프만 선택 → E
    E는 Extrude(뽑아내기)예요. 목선에서 새 면을 뽑아 카라를 만들어요.

  7. Mirror 잠깐 끄기모디파이어

    Mirror 모디파이어의 뷰포트 표시 끄기
    Mirror는 반쪽을 반대편에 거울처럼 복사해 주는 모디파이어예요. 카라 모양을 잡는 동안 잠깐 꺼요.

  8. 카라 접힌 모양 만들기메시 편집

    뽑은 엣지의 높이를 살짝 낮추기 → 한 번 더 E 로 올리기 → 위에서 본 뷰(` → Top)에서 S 로 벌리기
    카라가 바깥으로 접혀 내려오는 모양이 돼요.

  9. Mirror 켜고 앞쪽 떼기메시 편집

    Mirror 다시 켜기 → 앞 중앙에서 붙어 버린 카라 점을 떨어지게 빼기
    Mirror를 켜면 앞 중앙에서 카라가 붙어 버려요. 앞쪽은 벌어져 있어야 해요.

  10. 뒤쪽은 중앙에 붙이기메시 편집

    Clipping 켠 상태에서 뒤쪽 점 선택 → G X 로 중앙에 붙이기
    Clipping은 중앙선에 닿은 점을 붙잡아 주는 옵션이에요. 뒷목 쪽 카라는 이어져 있어야 해요.

  11. 루프컷 추가메시 편집

    카라가 옷을 파고드는 곳에 Ctrl R 로 루프컷을 과감히 추가 → 모양 잡기
    Ctrl+R은 메시를 빙 두르는 선을 추가해요. 몸이 최소한의 로우폴리라 선이 모자라서 생기는 문제예요.

  12. 카라 높게 띄우기메시 편집

    카라를 높게 올리기 → 옆에서 봤을 때 물결치지 않게 정리 → 루프컷을 더 넣어 둥근 카라로
    가디건 위로 카라가 보여야 해요.

  13. 가파른 곳 Smooth메시 편집

    가파른 부분의 점 선택 → Smooth
    점들을 평평하게 펴서 울퉁불퉁한 곳을 완만하게 해요.
    Smooth를 여는 메뉴나 단축키는 강의 자막에 없어요.

리본 (큐브에서 새로 모델링)

8:56~15:17

매듭과 날개로 된 리본이 카라 앞에 놓여 있어요.

  1. 매듭용 큐브 추가메시 편집

    Shift A → Mesh → Cube → 작게 줄여 카라 앞에 배치
    리본 가운데 매듭이 될 상자예요.

  2. 반으로 자르기메시 편집

    Edit Mode → 반으로 자르기 → X-ray 켜기 → 왼쪽 절반 선택해 삭제
    반쪽만 만들고 나머지는 Mirror가 복사하게 할 거예요.

  3. Mirror 추가모디파이어

    Q → Mirror
    Q는 즐겨찾기(Quick Favorites) 메뉴예요. 강사는 여기에 Mirror를 넣어 뒀어요.
    즐겨찾기에 Mirror가 없으면 Add Modifier에서 Mirror를 추가하세요.

  4. Subdivision 레벨 1모디파이어

    Ctrl 1
    Subdivision 모디파이어를 레벨 1로 붙여요. 면을 잘게 나눠 둥글게 보여 줘요.
    나중에 레벨을 2로 올려요.

  5. 납작하게이동·변형

    S Y
    앞뒤(Y축) 방향으로만 줄여서 납작하게 해요.

  6. Shade Auto Smooth 80도음영·노멀

    Shade Auto Smooth → 각도 80
    면 사이 각도가 80도보다 완만한 곳은 매끈하게 보이게 해요. 강사가 계속 쓰는 약속의 값이에요.

  7. 날개용 큐브 추가메시 편집

    Shift A → Mesh → Cube
    리본 양옆 날개가 될 상자예요.

  8. 날개에 Mirror모디파이어

    Q → Mirror → Mirror Object 에 매듭 큐브 지정
    매듭을 기준으로 반대쪽에 날개가 복사돼요.

  9. Subdivision 레벨 2모디파이어

    Ctrl 2
    날개에 Subdivision 레벨 2를 붙여요.

  10. On Cage 켜기모디파이어

    Subdivision 모디파이어의 Edit Mode 표시 버튼과 On Cage 버튼(세모) 켜기
    둥글어진 결과 모양을 보면서 편집할 수 있어요.

  11. 리본 모양 잡기메시 편집

    루프컷을 넣어 리본 모양 만들기 → X-ray 켜고 루프컷을 더 넣어 선택 → 바깥쪽을 빼 주기
    선을 더 넣고 바깥을 빼면 빵빵해 보여요.

  12. 매듭 쪽 가늘게메시 편집

    매듭 쪽(안쪽) 선택 → S Y
    매듭에 묶인 쪽은 가늘어야 리본 같아요.

  13. 날개 중간 도톰하게메시 편집

    날개 중간 선택 → G Y
    가운데를 앞으로 빼서 도톰하게 해요.
    리본 뒷면에는 디테일을 넣지 마세요. 옷에 붙어 안 보이고 색칠만 어려워져요.

  14. 리본 기울이기이동·변형

    매듭과 날개 두 오브젝트 함께 선택 → R
    리본을 옷에 맞게 기울여요.

  15. 두께 조절이동·변형

    S Y Y
    Y를 두 번 누르면 오브젝트 자신의 Y축(로컬)이에요. 기울어진 리본의 두께만 바꿔요.

  16. Random 색으로 보기화면

    뷰포트 셰이딩 옵션 → Color → Random
    오브젝트마다 다른 색으로 보여서 구분이 쉬워요.
    구분이 안 될 때만 쓰세요.
강사의 팁
  • 카라와 리본 중 무엇을 앞으로 낼지는 취향이에요.

가디건

15:28~21:52

앞이 열리고 소매 끝이 막힌 오버핏 가디건이 만들어져 있어요.

  1. 상체+팔 복제·분리메시 편집

    Body Edit Mode → 블라우스와 많이 겹치는 영역과 손목까지 팔 전체 선택 → Shift D → P → Selection
    가디건의 바탕이 될 면을 떼어 내요.

  2. 두툼하게 키우기이동·변형

    전체 선택 → Alt S 로 블라우스보다 두툼하게
    가디건은 블라우스 위에 입는 옷이라 더 커야 해요.
    카라를 뚫지 않을 만큼 키우세요.

  3. 앞 중앙 면 삭제메시 편집

    앞 중앙 면 선택 → X → Faces
    앞이 열린 옷이라 가운데 면을 지워요.

  4. 소매 끝 넓히기이동·변형

    소매 끝 선택 → S → Shift X. 두 번 반복
    Shift+X는 X축만 빼고 크기를 바꿔요. 팔 길이는 그대로 두고 굵기만 커져요.

  5. 밑단 늘리기메시 편집

    밑단 엣지 선택 → E Z
    아래 방향으로 면을 뽑아 가디건을 길게 해요.

  6. 밑단 수평 맞추기이동·변형

    S Z 0
    Z축 크기를 0으로 만들면 점들이 같은 높이로 나란히 정렬돼요.

  7. 밑단 살짝 넓히기이동·변형

    Proportional Editing 켜기 → 밑단을 살짝 넓히기
    주변까지 부드럽게 같이 넓어져요.
    엉덩이가 너무 방방해지지 않게 하세요.

  8. 앞단 정렬이동·변형

    앞단 점 선택 → S X 0
    앞섶의 점들을 좌우 방향으로 한 줄에 맞춰요.

  9. 소매 끝에 턱 만들기메시 편집

    소매 끝 루프 선택 → E S 로 안쪽으로 줄이기
    옷 두께만큼의 턱을 만들어요. 소매가 뚫려 있으면 아웃라인이 생겼을 때 이상해요.

  10. 안쪽으로 밀어 넣기메시 편집

    E 로 안쪽(팔 방향)으로 밀어 넣기
    소매 속이 깊어 보이게 해요.
    밀어 넣은 부분이 소매 바깥 첫 엣지 루프보다 더 깊이 들어가면 포즈를 잡을 때 꼬여요. 그 사이까지만 넣으세요.

  11. 구멍 막기메시 편집

    한 번 더 E → M → At Center
    M은 Merge(합치기)예요. 뽑은 점들을 가운데 한 점으로 모아 구멍을 막아요.

  12. 점 사이 엣지 잇기메시 편집

    엣지가 없는 곳의 점 두 개 선택 → J
    J는 Connect Vertex Path예요. 두 점 사이에 선을 만들어 줘요.

  13. 날카로운 선 Mark Sharp음영·노멀

    옷깃처럼 날카로워야 하는 엣지 선택 → 우클릭 → Mark Sharp

  2. Cloth-On 키 만들기쉐이프 키

    Cloth-On이 선택되고 값이 1인 상태에서 수정해야 그 키에 저장돼요. Basis가 선택된 채 수정하면 기본 모양이 바뀌니 조심하세요.

  4. 팔 가늘게쉐이프 키

    Edit Mode에서 팔 선택 → S → Shift X

    어깻죽지처럼 옷을 고쳐도 끝이 없는 곳은 몸을 줄여서 해결해요.

  6. 포즈로 확인리깅

    여러 포즈로 돌려 가며 뚫리는 곳이 없는지 확인
    한 자세에서 괜찮아도 다른 자세에서 뚫릴 수 있어요.
강사의 팁
  • Warudo는 VRM의 쉐이프 키를 프로그램 안에서 켤 수 있어요. 옷을 입은 상태에서 Cloth-On을 1로 두면 유니티에서 따로 손대지 않아도 돼요.

가디건에 가려 안 보이는 블라우스 면이 지워져 뚫림이 없어져요.

  1. 가려진 블라우스 면 삭제메시 편집

    블라우스 Edit Mode → 가디건에 가려 안 보이는 문제 영역의 면 선택 → 삭제
    팔을 움직이면 블라우스가 가디건을 뚫고 나와요. 가디건을 벗지 않을 거라 안 보이는 면은 지워도 돼요.
강사의 팁
  • 속옷까지 완벽히 하려면, 그 경우에 쓸 쉐이프 키를 따로 만들어 줄이는 방식으로 하세요.

Hair 아마추어를 Body 아마추어에 합치기

52:38~55:01

머리카락 본과 몸 본이 한 아마추어 안에 Body, Hair 컬렉션으로 나뉘어 들어 있어요.

  1. 본 컬렉션 이름 바꾸기리깅

    각 아마추어의 Object Data 탭 → Bone Collections → 기본 이름 Bones 를 머리카락 쪽은 Hair, 몸 쪽은 Body 로 바꾸기
    본 컬렉션은 본을 묶어 두는 그룹이에요. 합치기 전에 이름을 정해 둬야 합친 뒤에도 머리 본과 몸 본이 구분돼요.
    서로 다른 아마추어를 합칠 때는 항상 본 컬렉션 이름을 먼저 정하고 합치세요.

  2. Hair 원점 맞추기이동·변형

    Hair 아마추어 선택 → Ctrl A 로 트랜스폼 적용
    Hair 아마추어의 원점이 몸 아마추어(월드 원점)와 달라서 맞춰 줘요.
    Ctrl+A 메뉴에서 Location인지 All Transforms인지는 강의 자막에 없어요. 화면을 보고 맞추세요.

  3. 아마추어 합치기리깅

    Hair 아마추어 먼저 선택 → Shift+클릭으로 Body 아마추어 선택(활성) → Ctrl J
    머리 본을 움직여도 머리카락이 안 따라오던 문제를 풀려고 두 아마추어를 하나로 합쳐요. 마지막에 고른 몸 아마추어로 합쳐져요.

  4. 컬렉션으로 본 고르기선택

    Pose Mode → Bone Collections 에서 Body 또는 Hair 선택 → Select
    그 컬렉션에 든 본만 한 번에 선택돼요.

  5. 헤어 본 숨기기화면

    Bone Collections 의 Hair 옆 눈 아이콘 끄기
    머리카락 본이 안 보여서 몸 본 작업이 편해요.

  6. 손 본 따로 묶기(선택)리깅

    Edit Mode에서 손 본 선택 → 새 컬렉션 만들기 → Assign
    손만 따로 고르거나 숨기고 싶을 때 써요.
강사의 팁
  • Hair Root를 Head 본에 Parent로 거는 과정은 이 영상 자막에 없어요.

옷 머티리얼 준비

55:07~55:54

모든 의상이 Cloth 머티리얼과 2048 크기의 흰 Cloth 이미지를 함께 써요.

  1. Cloth 머티리얼 만들기재질·텍스처

    가디건 선택 → 머티리얼 슬롯에서 Body 머티리얼 삭제 → 새 머티리얼 만들기 → 이름 Cloth
    옷 전용 재질을 새로 만들어요.

  2. Cloth 이미지 만들기재질·텍스처

    Image Texture 노드 → New → 크기 2048 × 2048, 이름 Cloth, 색 흰색 → 연결
    옷 색을 칠할 이미지예요.

  3. 머티리얼 링크재질·텍스처

    나머지 의상 선택 → 마지막에 가디건을 활성으로 선택 → Ctrl L → Link Materials
    가디건의 Cloth 머티리얼이 모든 의상에 똑같이 들어가요.

  4. UV Editor에 이미지 띄우기UV
