EP.05

바디를 움직이자! 몸 리깅하고 색칠하기

손과 팔을 완전히 붙이고, 팔꿈치와 무릎 관절을 만든 뒤 몸 전체에 웨이트를 넣어 뼈를 따라 움직이게 해요. 마지막에 바디 재질을 만들고 UV를 펴서 피부와 속옷을 색칠해요.

강의 영상 열기
손과 손목 접합 마무리팔꿈치와 무릎 관절 토폴로지몸 버텍스 그룹 준비초기 웨이트 수동 Assign뼈 부모 수정웨이트 스무스 작업 흐름팔꿈치·손목·무릎 수치 웨이트발, 발끝, 다리 옆바디 머티리얼UV 펼치기텍스처 페인트

손과 손목 접합 마무리

0:00~0:48

손목 점들이 팔 끝 점과 진짜로 하나로 합쳐져 있어요.

  1. 손목 점 병합하기메시 편집

    손 쪽 점 먼저 선택 → Shift+클릭 으로 팔 쪽 가까운 점 선택 → M → At Last
    지난 편에 스냅으로 붙인 점은 겹쳐만 있고 합쳐지지 않았어요. At Last는 마지막에 고른 팔 쪽 점 위치로 합쳐요.
    선택 순서가 중요해요. 손 쪽 먼저, 팔 쪽 나중이에요.

  2. 나머지 쌍 반복하기메시 편집

    같은 순서로 다음 점 쌍 선택 → Shift R
    Repeat Last는 방금 한 작업을 한 번 더 해 줘요. 메뉴를 다시 열지 않아도 돼요.
    중간에 다른 키를 누르면 반복되는 작업이 바뀌어요.

팔꿈치와 무릎 관절 토폴로지

0:48~3:50

팔꿈치와 무릎에 3줄 관절이 생겨서 잘 접히는 구조가 되어 있어요.

  1. 팔꿈치 베벨하기메시 편집

    팔꿈치 루프 선택 → Ctrl B → 가운데 선이 하나 더 생기게(3줄)
    Bevel로 선 하나를 3줄로 벌려요. 손가락 관절과 같은 구조예요.
    강의 자막에는 Ctrl P라고 나오지만 베벨은 Ctrl+B예요.

  2. 팔꿈치 안쪽 엣지 지우기메시 편집

    접히는 안쪽 엣지 선택 → Ctrl X
    접히는 쪽은 살이 포개지니 줄을 줄여요. Dissolve는 구멍 없이 선만 지워요.

  3. 팔꿈치 면 정리하기메시 편집

    점 두 개 선택 → J
    선을 지우고 남은 면을 점과 점을 이어서 깔끔하게 나눠요.

  4. 딱딱한 구간에 루프 컷메시 편집

    Ctrl R → 경사가 가파르고 딱딱해 보이는 구간에 넣어요
    줄을 하나 더 넣으면 급하게 꺾인 면이 부드러워져요.

  5. 비례 편집으로 다듬기이동·변형

    Proportional Editing 켜기 → 점을 옮겨 형태를 다듬어요
    주변 점이 함께 따라와서 자연스러운 곡면이 돼요.

  6. 버텍스 Smooth로 펴기메시 편집

    울퉁불퉁한 점 선택 → 버텍스 Smooth
    점들의 간격을 고르게 해서 표면을 펴 줘요.
    옷으로 가려질 부분이라 약간 딱딱한 음영은 무시해도 돼요.

  7. 무릎 베벨하기메시 편집

    무릎 루프 선택 → Ctrl B → 가운데 선 추가
    무릎도 팔꿈치와 같은 방법으로 3줄 관절을 만들어요.

  8. 무릎 안쪽 엣지 지우기메시 편집

    안쪽 면의 엣지 선택 → Ctrl X
    무릎 뒤 접히는 쪽 줄을 줄여요.

  9. 무릎 면 정리하기메시 편집

    점 두 개 선택 → J
    남은 면을 이어서 정리해요.

  10. 날카로운 곳 살짝 펴기메시 편집

    날카로운 부분의 점을 살짝 펴요
    너무 각진 곳만 부드럽게 해요.
    너무 많이 펴면 관절을 움직일 때 이상해져요.

몸 버텍스 그룹 준비

3:50~6:55

몸 뼈 이름의 빈 버텍스 그룹이 생기고, 목록이 부위별로 정리되어 있어요.

  1. 바디를 뼈에 연결하기리깅

    바디 선택 → Shift+클릭 으로 아마추어 선택 → Ctrl P → Armature Deform → With Empty Groups
    몸 뼈 이름과 같은 빈 버텍스 그룹이 추가돼요. 기존 손가락 그룹은 그대로 남아요.
    아마추어를 마지막에 선택해요.

  2. 구분용 그룹 만들기웨이트

    버텍스 그룹 목록에서 새 그룹 추가 → 기호로 된 이름(구분선)으로 바꿔요 (여러 개)
    그룹이 너무 많아 알아보기 어려워서, 기능은 없고 칸막이 역할만 하는 그룹을 끼워 넣어요.
    강의 자막에 정확한 기호 이름이 없어요. 화면을 보고 맞추세요.

  3. 그룹 순서 정리하기웨이트

    그룹 선택 → 목록 옆 위/아래 화살표로 옮겨요: 손가락 / Hand / 팔·어깨 L·R / 다리 L·R / 몸통
    부위별로 묶어 두면 웨이트 작업할 때 그룹을 빨리 찾아요.

초기 웨이트 수동 Assign

6:55~9:10

몸의 모든 부위가 자기 뼈 그룹에 Weight 1로 들어가 있어요.

  1. X-Ray 켜기화면

    Edit Mode → X-Ray 켜기
    X-Ray를 켜야 뒤쪽에 가려진 점까지 한꺼번에 선택돼요.
    꼭 켜세요. 안 켜면 앞쪽 점만 들어가요.

  2. 엉덩이 → Hips웨이트

    엉덩이 영역 선택 → Hips 그룹 → Weight 1 → Assign
    엉덩이 부분이 Hips 뼈를 따라가게 해요.
    선택 범위는 화면을 보고 맞추세요.

  3. 허리 → Spine웨이트

    허리 영역 선택(경계선 포함) → Spine 그룹 → Weight 1 → Assign
    허리 부분이 Spine 뼈를 따라가게 해요.

  4. 가슴 → Chest웨이트

    가슴 영역 선택 → Chest 그룹 → Weight 1 → Assign
    가슴 부분이 Chest 뼈를 따라가게 해요.

  5. 목 → Neck웨이트

    목 영역 선택 → Neck 그룹 → Weight 1 → Assign
    목 부분이 Neck 뼈를 따라가게 해요.
    Head와 Eye는 지난 편에서 끝냈어요.

  6. 어깨 → Shoulder.L웨이트

    어깨 쪽 네 칸 정도 선택 → Shoulder.L 그룹 → Weight 1 → Assign
    어깨 부분이 어깨 뼈를 따라가게 해요.

  7. 위팔 → UpperArm.L웨이트

    위팔 루프 선택 → 메뉴 Select → More 로 선택 넓히기 (강의는 Ctrl+넘패드 +) → UpperArm.L 그룹 → Weight 1 → Assign
    Select More는 선택한 곳 옆 칸까지 선택을 넓혀 줘요. 위팔 전체를 빠르게 골라요.

  8. 아래팔 → LowerArm.L웨이트

    아래팔 루프 선택 → 메뉴 Select → More (강의는 Ctrl+넘패드 +) → LowerArm.L 그룹 → Weight 1 → Assign
    아래팔이 LowerArm 뼈를 따라가게 해요.

  9. 허벅지 → UpperLeg.L웨이트

    허벅지 루프 선택 → 메뉴 Select → More (강의는 Ctrl+넘패드 +) → UpperLeg.L 그룹 → Weight 1 → Assign
    허벅지가 UpperLeg 뼈를 따라가게 해요.

  10. 종아리 → LowerLeg.L웨이트

    발목 쪽까지 선택 → LowerLeg.L 그룹 → Weight 1 → Assign
    종아리가 LowerLeg 뼈를 따라가게 해요.

  11. 발 부분은 빼기웨이트

    발 부분 선택 → LowerLeg.L 그룹 → Remove
    발까지 같이 선택됐다면 발은 LowerLeg에서 빼야 해요. 발은 Foot 뼈가 맡아요.
    발까지 선택됐을 때만 해요.

  12. 발 → Foot.L웨이트

    발 전체 선택 → Foot.L 그룹 → Weight 1 → Assign
    발이 Foot 뼈를 따라가게 해요.

  13. 발끝 → Toe.L웨이트

    발끝만 선택 → Toe.L 그룹 → Weight 1 → Assign
    발끝이 Toe 뼈를 따라가게 해요.
    Foot과 Toe가 거의 겹쳐 들어가요. 뒤에서 조정해요.

뼈 부모 수정

9:10~9:50

손 뼈가 아래팔 뼈의 자식이 되어 팔을 움직이면 손이 따라와요.

  1. Hand.L 부모 지정리깅

    뼈 Edit Mode → Hand.L 선택 → Bone 탭 → Parent → LowerArm.L
    Hand.L의 부모가 비어 있어서 팔을 움직여도 손이 안 따라와요. 아래팔을 부모로 정해요.

  2. Hand.R 부모 지정리깅

    Hand.R 선택 → Bone 탭 → Parent → LowerArm.R
    반대쪽은 자동으로 되지 않아서 직접 정해 줘야 해요.

웨이트 스무스 작업 흐름

9:50~19:20

허리, 가슴, 엉덩이, 어깨를 움직여도 경계가 딱딱하게 꺾이지 않아요.

  1. 뼈 돌려 문제 찾기리깅

    Pose Mode → 뼈 선택 → R Z
    뼈를 돌려 봐야 어색한 곳이 드러나요. 몸통은 옆으로 기울이는 R Z가 문제를 가장 빨리 보여 줘요.

  2. 포즈 상태로 편집하기모디파이어

    바디의 Armature 모디파이어 → Edit Mode 버튼(네모)과 On Cage 버튼(세모) 켜기
    뼈를 돌린 자세 그대로 Edit Mode에서 점을 고를 수 있어요.

  3. 문제 영역 스무스웨이트

    Edit Mode에서 어색한 영역의 버텍스나 면 선택 → Weight Paint 모드 → 마스크 켜기 → 관련 그룹을 하나씩 선택 → Q → Smooth (2~3회)
    마스크를 켜면 선택한 곳에만 Smooth가 걸려요. 이웃 점끼리 웨이트가 섞여 부드러워져요.
    이 절차를 부위마다 반복해요.

  4. 점 값 직접 고치기웨이트

    문제 버텍스 선택 → N 패널 → Vertex Weights 값을 직접 조정
    Smooth로 안 고쳐지는 점은 숫자를 직접 바꿔요.

  5. 잘 맞는 값 복사하기웨이트

    복사 받을 점들 선택 → 잘 맞는 점을 마지막에 선택 → N 패널 Vertex Weights → Copy 버튼
    잘 맞춘 점의 웨이트를 선택한 다른 점들에 똑같이 넣어 줘요.

  6. 허리 스무스웨이트

    Spine을 돌려 확인 → 경계 영역 선택 → Spine, Chest, Hips 순으로 Smooth
    허리 경계에 세 뼈의 값이 고르게 섞여야 부드럽게 휘어요.
    Hips를 돌리면 몸 전체가 돌아가요. Hips는 주변 뼈(Spine, 다리)를 움직여서 확인하세요.

  7. 가슴 스무스웨이트

    Chest 선택 → R Z → 어색한 면 선택 → Spine, Chest 그룹 Smooth
    가슴과 허리 사이 경계를 부드럽게 해요.

  8. 엉덩이·다리 뿌리 스무스웨이트

    다리를 들어 확인 → 어색한 영역 선택 → Hips, UpperLeg 그룹 Smooth
    다리를 들었을 때 엉덩이가 자연스럽게 따라오게 해요.
    Hips Smooth가 오히려 어색하면 Spine만 하세요.

  9. 비어 보이는 곳 채우기웨이트

    비어 보이는 점 선택 → Vertex Weights 에서 Spine, Hips 값을 직접 조절
    웨이트가 모자라 안 따라오는 점에 값을 채워 줘요.
    강의 자막에 수치가 없어요. 화면을 보고 맞추세요.

  10. 팔꿈치·무릎 튀는 점웨이트

    튀는 버텍스 선택 → UpperArm, LowerArm (무릎은 UpperLeg, LowerLeg) 그룹 Smooth
    관절 주변에서 혼자 튀어나오는 점을 주변과 맞춰요.

  11. 어깨 스무스웨이트

    Shoulder를 올려 확인 → 어색한 영역 선택 → Shoulder, UpperArm 그룹 Smooth
    어깨와 팔 사이 경계를 부드럽게 해요.

  12. 어깨에 Chest 값 넣기웨이트

    어깨 주변 선택 → Chest 그룹 Smooth
    어깨가 몸에 안 붙으면 Chest 값이 빠져 있어서 그래요. 어깨, 가슴, 팔 세 그룹이 이어져야 해요.
    뭔가 이상하면 대개 어깨, 가슴, 팔이 서로 이어져 있지 않아서예요.

  13. 움푹한 곳 고치기웨이트

    움푹 들어가는 점 선택 → Vertex Weights 에서 Shoulder 값을 줄여요
    어깨 뼈를 너무 많이 따라가서 꺼지는 거라 값을 낮춰요.
    강의 자막에 수치가 없어요. 화면을 보고 맞추세요.

  14. 필요 없는 그룹 지우기웨이트

    점 선택 → Vertex Weights 목록에서 필요 없는 그룹 옆 X 버튼 → 그 자리는 UpperArm 그룹 Smooth 로 채워요
    한 점에 뼈 4개가 영향을 주면 복잡해져요. 0.0015 같은 아주 작은 값은 지워요.

  15. 어깨와 팔 함께 테스트리깅

    Shoulder와 팔 뼈 함께 선택 → 피벗 Individual Origins → R X X 또는 R Z Z
    실제 사람은 팔만 따로 올리지 못해요. 어깨와 팔을 같이 돌려 봐야 진짜 쓰는 포즈가 보여요.
    어깨를 고정하고 팔만 돌렸을 때 생기는 알통이나 꺼짐은 고민하지 않아도 돼요.

팔꿈치·손목·무릎 수치 웨이트

19:20~26:40

팔꿈치, 손목, 무릎이 0.5 / 0.8 / 0.9 규칙으로 깔끔하게 꺾여요.

  1. 팔 펴기리깅

    팔 뼈의 포즈를 되돌려 편 상태로 만들어요
    팔을 편 상태에서 작업해야 줄이 잘 보여요.

  2. 팔꿈치 가운데 0.5웨이트

    팔꿈치 가운데 줄의 점 선택 → Vertex Weights → UpperArm 0.5, LowerArm 0.5
    관절 가운데는 두 뼈를 반반씩 따라가요.

  3. 팔꿈치 옆 줄 0.8 / 0.2웨이트

    가운데 옆 줄 선택 → 가까운 쪽 뼈 0.8, 반대쪽 뼈 0.2
    가운데에서 한 칸 멀어지면 가까운 뼈를 더 많이 따라가요.

  4. 팔꿈치 바깥 줄 0.9 / 0.1웨이트

    그 바깥 줄 선택 → 가까운 쪽 뼈 0.9, 반대쪽 뼈 0.1
    값이 서서히 바뀌어야 관절이 자연스럽게 꺾여요.

  5. 같은 줄에 복사하기웨이트

    같은 줄의 점들 선택 → 값을 넣은 점을 마지막에 선택 → Vertex Weights → Copy 버튼
    점 하나에 넣은 값을 같은 줄 전체에 한 번에 넣어요.

  6. 손목에 루프 컷 추가메시 편집

    Ctrl R → 손목에 1개
    손목은 줄이 모자라서 관절 3줄을 만들려면 하나 더 필요해요.

  7. 손목 가운데 0.5웨이트

    손목 가운데 줄 선택 → Hand 0.5, LowerArm 0.5
    손목 가운데는 손과 아래팔을 반반씩 따라가요.

  8. 손목 팔 쪽 줄웨이트

    팔 쪽 줄 선택 → LowerArm 0.9, Hand 0.1
    팔에 가까운 줄은 아래팔을 더 많이 따라가요.

  9. 손목 손 쪽 줄웨이트

    손 쪽 줄 선택 → Hand 0.9, LowerArm 0.1
    손에 가까운 줄은 손을 더 많이 따라가요.

  10. 다리 펴기리깅

    다리 뼈의 포즈를 되돌려 편 상태로 만들어요
    다리도 편 상태에서 작업해야 잘 보여요.

  11. 무릎 웨이트 넣기웨이트

    무릎 가운데 줄: UpperLeg 0.5, LowerLeg 0.5 → 옆 줄: 가까운 쪽 0.8, 반대쪽 0.2 → 바깥 줄: 가까운 쪽 0.9, 반대쪽 0.1
    무릎도 팔꿈치와 똑같은 규칙이에요.
관절줄웨이트
팔꿈치가운데 줄UpperArm 0.5 / LowerArm 0.5

강사의 팁
  • 더 뾰족한 팔꿈치를 원하면 루프 컷과 뼈를 더 추가해야 하지만 SD에서는 생략해요.
  • 관절이 호스처럼 둥글게 휘도록 너무 부드럽게 하면 안 돼요. 강사 말로는 교통사고 난 다리처럼 보여요. 꺾이는 느낌은 남겨 두세요.

발, 발끝, 다리 옆

26:40~30:05

발목과 다리 뿌리가 움직여도 어색하지 않아요.

  1. 발목 스무스웨이트

    발 전체 면 선택 → LowerLeg, Foot, Toe 그룹을 각각 Smooth 약 3회
    발목 주변에 세 뼈의 값을 섞어서 부드럽게 해요.
    정답은 없어요.

  2. 파묻히는 곳 고치기웨이트

    파묻히는 점 선택 → Vertex Weights 값을 직접 조절하거나 Smooth를 더 해요
    발목을 꺾을 때 안으로 들어가는 점을 꺼내요.
    가장 좋은 해법은 루프 컷으로 면을 늘리는 것이에요. 강사는 Smooth를 더 하는 것으로 대신했어요.

  3. 다리 뿌리 스무스웨이트

    다리를 옆으로 벌려 확인 → 다리 뿌리 면 선택 → UpperLeg.L 그룹만 Smooth
    다리를 옆으로 벌렸을 때 뿌리가 부드럽게 이어지게 해요.
    Hips 값은 건드리지 마세요. SD 특유의 통통한 엉덩이 볼륨이 사라져요. L과 R 그룹을 헷갈리지 않게 조심하세요.
강사의 팁
  • Toe 뼈는 안짱다리 같은 발끝 방향을 표현하는 용도예요. 문제가 거의 없어요.

바디 머티리얼

30:05~31:15

바디에 body 재질이 있고, 흰색 2048 이미지가 그대로 보이게 연결되어 있어요.

  1. Shader Editor 창 열기화면

    창을 하나 더 나눠요 → 에디터 종류를 Shader Editor 로
    Shader Editor는 재질을 노드(상자)로 이어서 만드는 창이에요.

  2. 새 머티리얼 만들기재질·텍스처

    바디 선택 → 새 머티리얼 추가 → 이름 body
    머티리얼은 물체의 색과 질감을 정하는 재질이에요.

  3. Principled BSDF 지우기재질·텍스처

    Principled BSDF 노드 선택 → 삭제
    빛 계산을 하는 기본 노드를 빼요. Head와 같은 방식으로 이미지 색이 그대로 보이게 하려는 거예요.

  4. Image Texture 노드 추가재질·텍스처

    Image Texture 노드를 추가해요
    그림 파일을 재질에 쓰게 해 주는 노드예요.

  5. 새 이미지 만들기재질·텍스처

    Image Texture 노드 → New → 이름 body, 2048 × 2048, 색 흰색
    여기에 피부와 속옷을 색칠해요. 2048은 그림의 가로세로 픽셀 수예요.

  6. 출력에 직접 연결재질·텍스처

    Image Texture 노드의 Color → Material Output 에 직접 연결
    그림자 계산 없이 이미지 색이 그대로 보여요. 이런 방식을 언릿이라고 해요.

UV 펼치기

31:15~38:30

바디의 UV가 부위별로 펴져서 색칠할 수 있게 배치되어 있어요.

  1. 부위 경계에 SeamUV

    다리 뿌리, 팔(어깨 쪽), 손목 엣지 선택 → Mark Seam
    UV는 입체를 평면으로 펼친 전개도예요. Seam은 가위로 자르는 선이라 부위별로 나눠 줘요. UV를 안 펴면 색칠이 안 돼요.

  2. 팔다리 길이 방향 SeamUV

    팔과 다리의 길이 방향 엣지 한 줄 선택 → Mark Seam
    팔다리는 원통이라 길게 한 줄 잘라야 평평하게 펴져요.
    다리는 티가 덜 나는 안쪽을 자르세요.

  3. 발 SeamUV

    발목 엣지와 발바닥 둘레 엣지 선택 → Mark Seam
    발을 다리에서 떼고 발바닥도 따로 떼어 내요.

  4. 손가락 SeamUV

    손가락 뿌리 엣지를 각각 선택 → Mark Seam
    손가락을 하나씩 따로 떼면 색칠하기 편해요.

  5. 손등·손바닥 SeamUV

    손을 손등과 손바닥으로 반 가르는 엣지 선택 → Mark Seam
    손이 장갑 모양으로 펴져요.
    손톱 반대 방향(손바닥 쪽)을 자르세요. 손톱 그릴 면이 온전히 남아요.

  6. Unwrap 하기UV

    전체 선택 → Unwrap
    Seam을 따라 메시를 평면으로 펼쳐요.

  7. 덜 갈린 곳 다시 자르기UV

    덜 갈린 곳의 엣지 선택 → Mark Seam → 다시 Unwrap
    펼친 결과가 찌그러져 있으면 자를 선이 모자란 거예요.
    여러 번 반복하게 돼요.

  8. 아일랜드 확인하기UV

    UV Editor → UV 동기화 선택 버튼 켜기 → UV 조각을 눌러 3D 뷰에서 어느 부위인지 확인
    아일랜드는 UV에서 따로 떨어진 조각이에요. 동기화를 켜면 UV에서 고른 것이 3D 뷰에도 선택돼요.
    이 상태에서 UV를 움직이면 꼬여요. 확인용으로만 쓰고 다시 끄세요.

  9. 비례 편집 끄기파일·설정

    Proportional Editing 끄기
    켜져 있으면 조각 하나를 옮길 때 다른 조각까지 끌려와요.

  10. UV 조각 배치하기UV

    조각을 옮겨 배치해요: 바디 / 다리와 발바닥 / 팔 / 손등·손바닥 / 손가락(중지, 새끼, 약지, 엄지, 검지 순)
    어느 조각이 어느 부위인지 알아볼 수 있게 묶어 둬요.

  11. UV 크기 나누기UV

    손 조각은 크게, 팔다리와 몸통 조각은 작게 줄여요
    크게 놓은 조각일수록 그림이 선명해요. 손은 손톱을 그려야 하고, 팔다리와 몸통은 옷에 가려져요.
    남는 공간은 그대로 둬도 돼요.

텍스처 페인트

38:30~45:30

바디에 피부색, 목 그림자, 손톱, 속옷이 칠해지고 이미지가 파일로 저장되어 있어요.

  1. 피부색으로 채우기페인트

    Image Editor → Paint 모드 → Fill(페인트 통) 도구 → 피부색 선택 → 클릭
    이미지 전체를 피부색 한 가지로 채워요.

  2. 목 그림자 칠하기페인트

    가장 어두운 피부 그림자색 선택 → 목 부분을 강하게 칠해요
    턱 아래 그림자를 그림으로 넣는 거예요. 버추얼 캐릭터 채색의 큰 특징이에요.
    옷에 가려지니 넉넉하게 칠하세요. 브이넥처럼 파인 옷이면 가슴 위쪽까지 명암을 더 줘야 자연스러워요.

  3. 손톱 칠하기페인트

    손가락 끝에 손톱을 칠해요 (강의는 임시로 빨간색)
    손가락에는 명암을 넣지 않고 손톱만 그려요.

  4. 와이어프레임 켜기화면

    와이어프레임 표시를 켜요
    메시 선이 보여야 속옷 경계를 선에 맞춰 그릴 수 있어요.

  5. 속옷 경계선 그리기페인트

    브러시 설정 → Stroke Method → Line → 드래그 로 경계선을 그려요
    Line은 누른 곳부터 뗀 곳까지 직선을 그어 줘요. 속옷은 모델링하지 않고 그림으로 그려요.

  6. 속옷 안쪽 칠하기페인트

    Stroke Method → Space 로 되돌리기 → 경계선 안쪽을 칠해요
    Space는 평소처럼 붓질하는 방식이에요. 선 안쪽을 채워요.

  7. 리본 장식 그리기페인트

    속옷 앞면에 리본 장식을 그려요
    작은 장식을 넣어 포인트를 줘요.

  8. 와이어프레임 끄고 확인화면

    와이어프레임 표시를 끄고 선이 삐뚤지 않은지 봐요
    선을 끄고 보면 삐뚤어 보일 수 있어요.

  9. 이미지 저장하기파일·설정

    Image Editor → Image → Save → 바디 이미지 이름으로 저장
    칠한 그림은 블렌더 파일과 따로 저장해야 해요. 안 하면 그림이 사라질 수 있어요.
    페인트 후 이미지 저장을 잊지 마세요.
