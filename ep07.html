트윈테일 컬러링 & 찰랑 리깅

머리카락 전체에 재질 하나를 입혀 UV를 펴고 색을 칠한 뒤, VRM 재질(MToon)로 그림자색과 아웃라인을 넣어요. 그다음 머리카락 전용 본을 심고 웨이트를 넣어 찰랑거리게 만들어요.

머리카락 머티리얼 하나로 통일

0:00~1:00

모든 머리카락 메시가 Hair라는 같은 머티리얼과 같은 이미지를 쓰게 돼요.

  1. Hair 머티리얼 만들기재질·텍스처

    기준이 되는 앞머리 선택 → 새 머티리얼 생성 → 이름을 Hair 로 바꾸기
    머티리얼은 메시에 입히는 재질이에요. 머리카락은 전부 같은 머티리얼을 써야 해서 앞머리에 먼저 하나 만들어요.

  2. Principled BSDF 삭제재질·텍스처

    셰이더 에디터에서 Principled BSDF 노드 선택 → 삭제
    기본으로 들어 있는 재질 노드예요. 이미지를 바로 출력에 꽂아 쓸 거라 지워요.

  3. Hair 이미지 만들어 연결재질·텍스처

    Image Texture 노드 추가 → New → 이미지 이름 Hair → Material Output 에 연결
    색을 칠할 빈 이미지를 만들어 재질에 직접 꽂아요. 앞머리만 하얗게 보이면 정상이에요.
    이미지 해상도는 강의 자막에 없어요. 기본값을 그대로 쓴 것으로 보여요.

  4. 머티리얼 링크재질·텍스처

    나머지 머리카락 메시 전부 선택 → 마지막에 앞머리를 Shift+클릭해 활성으로 → Ctrl L → Link Materials
    마지막에 고른 앞머리의 머티리얼이 선택한 모든 메시에 똑같이 들어가요.
    머티리얼이 든 앞머리를 꼭 마지막에 선택해야 해요.

머리카락 UV 펴기: Seam 넣는 기준

1:00~12:00

머리카락 덩어리마다 겉면과 안쪽면이 나뉘도록 절개선(Seam)이 들어가 있어요.

  1. 다른 메시 숨기기화면

    작업할 머리카락 한 덩어리만 남기고 나머지는 눈 아이콘(뷰포트 표시) 끄기
    한 덩어리씩 펴야 헷갈리지 않아요. UV는 3D 표면을 이미지 위에 펼친 전개도예요.

  2. 겉면·안쪽면 Seam 넣기UV

    모델링 때 날을 세우려고 넣어 둔 엣지(핫핑크색으로 보이는 선)를 따라 선택 → Mark Seam
    Seam은 UV를 펼 때 가위로 자르는 선이에요. 겉면(앞)과 안쪽면(뒤)을 서로 다른 UV 조각(섬)으로 나눠요.
    Mark Seam을 여는 단축키나 메뉴 경로는 강의 자막에 없어요.

  3. 앞뒤가 붙은 곳 고치기메시 편집

    Mirror 모디파이어의 Clipping 잠깐 끄기 → 메시를 살짝 수정 → Clipping 다시 켜기
    앞면과 뒷면이 붙어 버린 곳이 있으면 UV가 제대로 안 나뉘어요.

  4. 작은 머리는 한 줄만UV

    애교머리 같은 작고 단순한 머리 → 안쪽 라인 한 줄만 Mark Seam → Unwrap
    작은 덩어리는 앞뒤로 나눌 필요 없이 한 번에 펴도 충분해요.

  5. 양갈래 심지 절개UV

    양갈래 큰 심지의 안쪽(머리에 붙는 쪽) 라인 선택 → Mark Seam → Unwrap
    잘 안 보이는 안쪽을 갈라서 펴면 이음매가 눈에 띄지 않아요.

  6. 안테나 펴기UV

    안테나 한쪽을 기준으로 Seam 넣기 → Unwrap
    가느다란 안테나는 한쪽만 잘라 펼쳐요.

  7. 두피 헤어는 그대로UV

    두피에 붙은 헤어(캡)는 건드리지 않기
    이미 UV가 정리돼 있어서 다시 펼 필요가 없어요.
강사의 팁
  • 헤어 이미지 한 장 안에 모든 머리카락 UV를 펴요.
  • 어떤 건 반으로 나누고 어떤 건 그냥 펼칠지는 자기 마음이에요. 펴 본 모양이 마음에 안 들면 다 나누면 돼요.

머리카락 UV 펴기: 앞머리·옆머리 Project From View + Pin

1:00~12:00

앞머리와 옆머리의 겉면 UV가 정면에서 본 모양 그대로 펴져 있어요.

  1. 앞면 섬만 선택선택

    Edit Mode에서 앞면(겉면)에 해당하는 면만 선택
    정면 모양대로 펼 부분만 골라요.

  2. 정면 뷰로 보기화면

    ` → Front (강의는 넘패드 1)
    다음 단계가 지금 보이는 화면 모양대로 UV를 만들기 때문에 정면으로 맞춰요.

  3. Project From ViewUV

    UV → Project From View
    지금 화면에 보이는 모양 그대로 UV가 생겨요. 정면에서 보이는 대로 칠할 수 있어요.

  4. 중앙 부분 PinUV

    UV 에디터에서 중앙 부분만 선택 → P
    Pin은 UV 점을 못 움직이게 고정하는 거예요. 고정된 점은 빨간 점으로 보여요.

  5. 다시 UnwrapUV

    Pin을 둔 상태에서 Unwrap
    고정한 부분은 정면 모양을 지키고 나머지만 펴져요. 조금 찌글거려도 정면 모양은 유지돼요.

  6. 뒷면 섬 줄여 고정UV

    뒷면(안쪽) 섬 선택 → 크기를 줄여 옆으로 옮기기 → 통째로 P
    뒷면은 어떻게 칠해도 상관없어요. 실수로 건드리지 않게 통째로 고정해 둬요.
강사의 팁
  • Project From View를 쓴 섬은 Pin으로 고정하고, 그냥 Unwrap한 섬은 Pin을 하지 않아요.

머리카락 UV 펴기: 섬 크기 규칙

1:00~12:00

잘 안 보이는 면의 UV 섬이 작게 정리돼 있어요.

  1. 안쪽 면 섬 작게UV

    안쪽 면(뒷면) 섬 선택 → 겉면 섬보다 작게 줄여서 배치
    겉과 안이 구분되고, 이미지 공간(해상도)도 아낄 수 있어요.

  2. 속머리 섬 작게UV

    뒷머리 속머리처럼 거의 칠하지 않을 부분의 섬을 작게 줄이기
    칠할 일이 거의 없는 곳에 넓은 자리를 줄 필요가 없어요.

체커 텍스처로 UV 밀도 맞추기

12:00~17:45

모든 머리카락 섬이 비슷한 크기 비율로 Hair 이미지 안에 겹치지 않게 놓여 있어요.

  1. Material Preview로 보기화면

    뷰포트 셰이딩 버튼 중 세 번째(Material Preview) 누르기
    재질과 텍스처가 보이는 화면 모드예요. 체커 무늬를 보려면 필요해요.

  2. Hair 이미지 노드 떼기재질·텍스처

    셰이더 에디터에서 Hair 이미지 노드의 연결선을 잠깐 끊기
    체커 무늬를 대신 꽂으려고 잠깐 떼어 둬요.

  3. Checker Texture 연결재질·텍스처

    셰이더 에디터에 Checker Texture 노드 추가 → 출력에 임시로 연결
    바둑판 무늬를 입히면 UV 섬마다 크기가 얼마나 다른지 눈으로 볼 수 있어요.

  4. UV 매핑 붙이기애드온

    Checker Texture 노드 선택 → Ctrl T
    Node Wrangler 애드온 기능이에요. Texture Coordinate와 Mapping 노드가 붙고 UV → Mapping → Checker 로 연결돼요.

  5. Checker Scale 50재질·텍스처

    Checker Texture 의 Scale 에 50 입력
    기본값으로는 네모가 보기 불편해서 알맞은 크기로 바꿔요.

  6. 전체 UV 줄이기UV

    Edit Mode에서 전체 UV 선택 → 일단 작게 줄이기
    섬 크기를 하나씩 맞추기 전에 자리를 넉넉히 만들어요.

  7. 섬 크기 맞추기UV

    앞머리를 기준 크기로 정하기 → 다른 섬들을 체커 네모 크기가 비슷해지도록 눈대중으로 스케일 조절
    어떤 머리는 잘 칠해지는데 어떤 머리는 텍스처가 깨져 보이는 일을 막아요.
    완벽히 같을 필요는 없어요. 양갈래는 끝으로 갈수록 UV가 뭉치지만 알고 칠하면 되니 그대로 둬요. 양갈래끼리는 무늬가 비슷하게 맞춰요.

  8. 섬 배치하기UV

    섬끼리 겹치지 않게, 이미지 밖으로 나가지 않게 옮겨 놓기
    섬이 겹치면 한 곳을 칠할 때 다른 머리카락까지 같이 칠해져요.

  9. 전체 키워서 채우기UV

    빈 공간이 남으면 섬 전체를 선택해 함께 키우기
    억지로 끼워 넣는 것보다 전체를 키우는 편이 크기 비율이 유지돼요.

  10. Hair 이미지 다시 연결재질·텍스처

    체커 노드 연결 끊기(삭제해도 됨) → Hair 이미지 노드를 다시 연결
    크기 맞추기가 끝났으니 색칠할 이미지로 되돌려요.
강사의 팁
  • 대충 칠할 거면 이 단계는 건너뛰어도 돼요.

머리카락 색칠: 베이스 색

17:45~33:45

Hair 이미지 전체가 머리 기본색으로 채워져 있어요.

  1. Texture Paint 열기화면

    위쪽 탭에서 Texture Paint 워크스페이스 선택
    색칠하기 좋게 화면이 배치된 작업 공간이에요.

  2. 왼쪽을 Image Editor로화면

    왼쪽 창을 UV Editor가 아니라 Image Editor 로, 모드는 Paint 로
    이미지 위에 바로 칠하려면 Paint 모드여야 해요.

  3. 베이스 색 채우기페인트

    Fill(페인트 통) 툴 선택 → 머리 기본색 고르기 → 이미지 클릭
    이미지 전체를 한 가지 색으로 채워요. 강사는 눈 색에 맞춰 파란색·남색 계열을 썼어요.
    정확한 색 코드는 강의 자막에 없어요. 화면을 보고 맞추세요.

  4. Face Orientation 끄기화면

    Overlays → Face Orientation 체크 끄기
    면의 앞뒤를 파랑·빨강으로 보여 주는 표시예요. 빨간 면이 보여 거슬리면 꺼요.

머리카락 색칠: 안쪽면 명암

17:45~33:45

머리카락 안쪽 면만 어두운 색으로 칠해져 겉과 안이 구분돼요.

  1. 명암색 만들기페인트

    베이스 색에서 조금 더 어둡게, 조금 더 푸르게, 채도는 살짝 낮게 조절
    안쪽 면에 칠할 그림자 색이에요.
    정확한 색 코드는 강의 자막에 없어요.

  2. 안쪽 면만 선택선택

    Edit Mode에서 머리카락 안쪽 면(뒷면)만 선택
    칠할 범위를 미리 골라 두면 그 면에만 색이 들어가요.

  3. 페인트 마스크 켜기페인트

    Texture Paint 모드에서 페인트 마스크(Face Selection Masking) 버튼 켜기
    Edit Mode에서 선택해 둔 면에만 칠해지게 막아 주는 기능이에요.

  4. 안쪽 면 칠하기페인트

    Fill 또는 브러시로 선택된 면 칠하기
    안과 밖이 구분되고, 얼핏 보이는 안쪽 면 덕분에 입체감이 생겨요. 강사가 가장 중요하다고 한 단계예요.

  5. Image Editor에서 직접 칠하기페인트

    Image Editor에서 해당 UV 섬 위를 직접 칠하기
    3D 화면에서 칠하기 어려운 곳은 펼쳐진 이미지 위에서 칠하는 게 편해요.
    옆 섬까지 크게 삐져나가면 다른 머리카락에 색이 묻어요. 적당히 칠하세요.

  6. 직선으로 절반만 칠하기페인트

    브러시 Stroke Method → Line 으로 바꾸기 → 섬의 절반만 칠하기
    안쪽이 따로 분리되지 않고 반이 이어진 섬은 직선으로 경계를 긋고 절반만 칠해요.

  7. 넓은 면 칠하기페인트

    Stroke Method → Space 로 되돌리기 → 브러시를 키워서 칠하기
    넓은 면적은 큰 브러시로 한 번에 칠하는 게 빨라요.
    브러시 크기 수치는 강의 자막에 없어요.
강사의 팁
  • 너무 귀찮으면 안쪽면 UV만 찾아서 포토샵이나 클립 스튜디오에서 칠해도 돼요.
  • 자신 없으면 정수리나 안쪽 부분만 적당히 칠해도 충분해요.

머리카락 색칠: 추가 명암

17:45~33:45

안테나 뿌리와 양갈래가 머리에 붙는 부분에 그림자가 들어가 있어요.

  1. 안테나 뿌리 명암페인트

    안테나 뿌리 쪽에 삐침 모양으로 어두운 색 칠하기 → 앞 섬과 뒤 섬 양쪽 다 칠하기
    앞뒤 섬이 이어져 보이도록 양쪽을 다 칠해요.

  2. 양갈래 붙는 곳 명암페인트

    양갈래에서 머리(헤드)에 붙는 영역만큼 어둡게 칠하기 → 뒤쪽은 더 넓게
    머리에 가려지는 부분에 그림자가 있어야 자연스러워요.
    소심하게 칠하면 안 보여요. 넉넉히 칠하세요.

  3. 돌려 보며 확인화면

    휠 드래그로 여러 각도에서 돌려 보며 어색한 곳 찾기
    한 방향에서만 보면 놓치는 곳이 생겨요.
    다른 머리에 가려 칠이 중간에 끊겨 보이는 건 정상이에요.

  4. 삐져나간 곳 정리페인트

    베이스 색을 골라 삐져나간 부분 덧칠하기
    지우개 대신 원래 색으로 덮어서 고쳐요.
    머리카락끼리 겹쳐서 어차피 가려지니 완벽할 필요는 없어요.

VRM 머티리얼(MToon)로 전환: 그림자색·아웃라인

머리카락에 MToon 그림자색과 검은 아웃라인이 들어가 있어요.

  1. VRM Material 켜기애드온

    Material 탭 아래쪽 VRM Material 패널의 체크박스 켜기
    VRM 애드온의 재질(MToon)로 바꿔요. 유니티의 MToon 셰이더 결과를 블렌더에서 미리 보는 용도예요.
    눌러도 반응이 없으면 블렌더를 저장하고 다시 시작하세요. 미리 보기는 유니티와 완전히 같지는 않아요.

  2. Lit Color에 이미지 넣기재질·텍스처

    Lit Color, Alpha 의 폴더 아이콘 → 방금 저장한 헤어 이미지 열기
    Lit Color는 빛을 받는 쪽의 색이에요. 칠한 이미지를 여기에 넣어요.

  3. Rendered로 보기화면

    뷰포트 셰이딩 버튼 중 네 번째(Rendered) 누르기
    빛과 그림자가 계산된 결과를 봐요. 하얗게 보이는 건 Shade Color(그림자색)가 흰색이라서예요.

  4. 그림자 영역 확인하기재질·텍스처

    Shade Color를 핑크로 바꾸기 → Shift A → Light → Sun → Sun의 각도를 돌려 보기
    Sun은 햇빛 같은 조명이에요. 그림자색을 튀는 색으로 바꾸고 조명을 돌리면 그림자가 어디에 지는지 보여요.
    확인용이에요.

  5. 색 그림자 없애기(선택)재질·텍스처

    Shade Color 텍스처에도 같은 헤어 이미지 넣기 → 색을 FFFFFF(흰색)로
    그림자에 따로 색이 끼는 게 싫을 때 쓰는 방법이에요.

  6. 그림자색 정하기재질·텍스처

    Shade Color 색을 머리색과 비슷하고 조금 밝은 색으로 바꾸기
    강사가 고른 설정이에요.
    정확한 색 코드는 강의 자막에 없어요.

  7. 아웃라인 켜기재질·텍스처

    Outline → None 을 맨 아래 Screen Coordinates 로 바꾸기
    아웃라인은 만화처럼 테두리에 그려지는 선이에요.

  8. 아웃라인 두께 0.005재질·텍스처

    두께 칸 클릭 → 0.005 입력
    선 굵기를 정해요.
    화면에는 0.00으로 줄여 보이지만, 칸을 클릭했을 때 보이는 값이 실제 값이에요.

  9. 아웃라인 색재질·텍스처

    아웃라인 색을 000000(검정)으로
    선 색이에요. 원하면 다른 색을 써도 돼요.

  10. 머리가 빨갛게 보일 때화면

    Overlays → Face Orientation 체크 바꾸기
    아웃라인은 면을 뒤집은 메시로 만들어져서 뒷면 표시(빨강)로 보일 수 있어요.
    켜는지 끄는지 강의 자막이 불명확해요. 앞에서는 끄면 된다고 했어요. 화면을 보고 정상으로 보이는 쪽으로 맞추세요.

  11. 선 두께가 다를 때이동·변형

    Hair 컬렉션의 오브젝트를 하나씩 선택 → Ctrl A → All Transforms
    오브젝트마다 스케일이 달라서 선 두께가 달라져요. 변형값을 적용해 스케일을 1로 맞춰요.

  12. 앞머리 경계선 그리기페인트

    텍스처 페인팅으로 앞머리 가닥 가장자리에 어두운 색 선을 직접 그리기
    아웃라인은 실루엣 가장자리에만 두껍게 생겨서 정면의 앞머리 가닥 경계는 잘 안 보여요. 그려서 보완해요.
    선택 사항이지만 퀄리티가 크게 올라간다고 강조했어요. 강사는 앞머리만 했어요. 버추얼은 정면을 주로 보기 때문이에요. 다 그린 뒤 이미지를 다시 저장하세요.

  13. 과한 선 지우기페인트

    뿌리 쪽 해당 면만 선택 → 페인트 마스크 켜기 → 지우기
    뿌리 쪽 선이 너무 진하면 그 면에서만 지워요.

  14. 애교머리 안으로 넣기이동·변형

    애교머리를 Y 방향으로 조금 안쪽으로 이동
    앞머리에 그린 선이 애교머리에 가려질 때 해요.

  15. Shading Toony 확인재질·텍스처

    Shading Toony 값 0.9 유지
    값을 낮추면 그림자 경계가 부드러워지고, 1이면 셀 애니메이션처럼 딱 끊겨요.

  16. Shading Shift 확인재질·텍스처

    Shading Shift 값 -0.2 유지
    1 쪽으로 가면 그림자가 약해지고, -1 쪽으로 가면 전체가 진해져요.

  17. Sun 라이트 정리기타

    Sun이 Hair 컬렉션에 들어가 있으면 Scene Collection 최상위로 빼서 맨 아래에 두기 → 눈 아이콘 끄기
    조명이 머리카락 컬렉션에 섞여 있으면 나중에 헷갈려요.

머리카락 본: 무엇을 흔들지 정하기

    리깅은 본(뼈)을 심어 메시를 움직이게 하는 작업이에요. 색 정보가 필요 없으니 가벼운 화면으로 바꿔요.

  2. 흔들 부위 정하기리깅

    앞머리 전체에 본을 넣으면 통째로 흔들려 보기 싫어요. 끝부분만 살짝 움직이게 해요.
    움직이는 게 싫은 덩어리는 빼도 돼요. 뒷모습을 안 쓸 거면 뒷머리도 생략할 수 있어요.

머리카락 본: 헤어 아마추어 만들기

45:43~1:24:33

Hair라는 새 아마추어와 기준 본 Hair Root가 머리 중심에 있어요.

  1. 새 아마추어 추가리깅

    Shift A → Armature → Single Bone
    아마추어는 본들을 담는 뼈대 오브젝트예요. 몸 본에서 이어 그리지 않고 머리카락용을 새로 만들어요.

  2. 이름·앞에 보이기화면

    Object Data(아마추어) 탭 → Viewport Display → Names 체크, In Front 체크
    본 이름이 화면에 보이고, 본이 메시에 가려지지 않고 항상 앞에 보여요.

  3. 아마추어 이름 Hair파일·설정

    아마추어 오브젝트 이름을 Hair 로 바꾸기
    몸 아마추어와 구분해요.

  4. Hair 컬렉션에 넣기파일·설정

    아마추어를 Hair 컬렉션으로 옮기기
    머리카락 관련 오브젝트를 한곳에 모아요.

  5. 첫 본 이름 Hair Root리깅

    첫 본의 이름을 Hair Root 로 바꾸기
    움직이지 않는 기준 본이에요. 모든 머리카락 본이 이 본에 매달려요.

  6. Hair Root 위치 잡기리깅

    Hair Root 를 머리 중심쯤으로 옮기기
    강사는 헤어뼈의 중심을 잘 잡아 주어야 한다고 했어요.
    정확한 위치 수치는 강의 자막에 없어요. 화면을 보고 맞추세요.

  7. Roll 0 확인리깅

    Item 패널에서 Roll 값이 0인지 확인
    Roll은 본이 자기 축을 따라 비틀린 정도예요. 0으로 맞춰 둬야 회전 방향이 깔끔해요.

머리카락 본: 본 만드는 공통 절차

45:43~1:24:33

머리카락마다 본 체인이 메시 속에 놓이고, 전부 Hair Root에 연결돼 있어요.

  1. Hair Root 복제리깅

    Edit Mode에서 Hair Root 선택 → Shift D
    새 본을 처음부터 만들지 않고 기준 본을 복제해서 시작해요.

  2. 아래로 뒤집기리깅

    R → 180 입력
    본이 아래를 향하게 해요. 작은 동그라미(tail)가 아래로 가야 해요.

  3. 이름 먼저 붙이기리깅

    본 이름 입력. 좌우가 있는 본은 처음부터 끝에 .L 붙이기
    .L은 왼쪽이라는 표시예요. 나중에 좌우 복사를 할 때 이 표시가 필요해요.
    나중에 .L을 붙이려면 번거로워요. 처음부터 붙이세요.

  4. Wireframe 표시 켜기화면

    메시의 Wireframe 표시 켜기
    메시의 선과 점이 보여야 본을 점 위치에 맞출 수 있어요.

  5. 스냅을 Vertex로이동·변형

    스냅(자석 아이콘) 켜기 → 대상을 Vertex 로
    본의 양 끝(head, tail)이 머리카락 점(버텍스)에 착 달라붙어요.

  6. 본 높이 맞추기리깅

    본의 head 또는 tail 선택 → G Z
    위아래(Z축)로만 움직여 머리카락 위치에 맞춰요.
    뿌리까지 흔들지 않을 거면 본 시작점을 뿌리보다 아래(중간쯤)에 두세요.

  7. 본을 메시 속에 넣기리깅

    스냅 끄기 → X-ray 켜기 → 앞·옆·위에서 보며 본이 메시 속에 오도록 옮기기 (` → Front / Right / Top)
    양갈래처럼 본이 메시 앞으로 튀어나올 때 해요. X-ray는 메시를 반투명하게 보여 주는 기능이에요.

  8. 본 이어 뽑기리깅

    본 끝 선택 → E 또는 E Z
    E는 Extrude(뽑아내기)예요. 본 끝에서 다음 본을 이어 만들어 체인을 만들어요.
    본이 많을수록 부드럽지만 느려져요. 너무 많으면 VRM 변환 때 계산을 못 할 수 있어요. 알맞은 개수의 법칙은 강사도 모른다고 했어요.

  9. Roll 전부 0으로리깅

    뽑아낸 본들 선택 → Item 패널에서 Roll 을 0 으로
    Extrude를 하면 Roll이 돌아가 있어요.

  10. Parent를 Hair Root로리깅

    체인의 첫 번째 본 선택 → Bone 탭 → Relations → Parent → Hair Root
    Parent(부모)를 정하면 부모 본이 움직일 때 같이 따라가요. 복제한 본은 부모가 비어 있어요.
    머리카락에 달린 모든 체인의 부모는 Hair Root 예요.

  11. 좌우 복사 Symmetrize리깅

    .L 본들 선택 → Armature → Symmetrize
    .L 본을 반대쪽에 .R 이름으로 복사해 줘요.
    이걸 빼먹으면 반대쪽 버텍스 그룹이 안 생겨요.

  12. 이름 빨리 붙이기리깅

    첫 본 이름 복사 → 다음 본 이름 칸에 붙여 넣기 → Enter
    같은 이름을 넣으면 뒤 숫자만 자동으로 바뀌어요.

머리카락 본: 웨이트 넣기 (Assign → Smooth)

45:43~1:24:33

본을 돌리면 머리카락이 부드럽게 휘어요.

  1. X-ray 켜기화면

    메시 Edit Mode → X-ray 켜기
    뒤쪽에 숨은 점까지 함께 선택되게 해요.
    반드시 켜세요.

  2. 뿌리를 Hair Root에웨이트

    본이 없는 뿌리 쪽 점 전부 선택 → 버텍스 그룹 Hair Root 선택 → Weight 1 → Assign
    웨이트는 점이 본을 얼마나 따라갈지 정하는 값(0~1)이에요. 뿌리는 안 움직이는 Hair Root에 붙여요.

  3. 구간별로 Assign웨이트

    각 본이 차지하는 구간의 점 선택 → 해당 본 이름의 그룹 선택 → Weight 1 → Assign
    본마다 자기 구간의 점을 움직이게 해요.
    경계는 겹쳐도 되고 넉넉하게 선택하세요. 어차피 Smooth로 풀려요.

  4. Pivot 바꾸기리깅

    Pose Mode → Pivot 을 Individual Origins 로
    여러 본을 한꺼번에 돌릴 때 각자 자기 자리에서 돌게 해요.

  5. 본 돌려 보기리깅

    체인의 본들 선택 → R X X
    X를 두 번 누르면 본 자신의 X축(로컬)으로 돌아요. 처음에는 딱딱하게 꺾여 보여요.

  6. 웨이트 Smooth웨이트

    딱딱한 영역의 점만 선택해 둔 채 Weight Paint 모드로 → Weights → Smooth → Hair Root 그룹부터 그룹마다 차례로 여러 번
    이웃한 그룹끼리 웨이트가 섞여 부드럽게 휘어요. 골고루 줘야 부드럽게 변해요.
    보통 2번, 양갈래는 4번씩이에요. 너무 많이 주면 뒤의 Limit Total 뒤에 원하는 느낌이 안 나와요.

  7. 끝부분 다듬기웨이트

    끝부분이 딱딱하면 끝쪽 웨이트를 더 다듬기
    머리카락 끝이 자연스럽게 휘게 해요.

  8. 가닥을 새 본으로 옮기기웨이트

    옮길 가닥의 점 선택 → 기존 그룹(Bang 2·3)에서 값 지우기 → 새 그룹(Bang 4·5)에 값 넣기
    중앙 본을 따르던 가닥을 새 본이 움직이게 바꿔요.

머리카락 본: 버텍스당 본 4개 제한

1:03:41~

어느 점도 본 4개까지만 영향을 받도록 정리돼 있어요.

  1. 전체 선택선택

    메시의 점 전체 선택
    모든 점에 제한을 걸기 위해서예요.

  2. Limit Total 4웨이트

    Weight Paint → Weights → Limit Total → Limit 에 4
    VRM은 한 점에 영향을 주는 본이 4개를 넘으면 계산 오류가 난다고 해요. 값이 가장 작은 그룹부터 자동으로 지워져요.
    아래쪽에 몇 개 점의 웨이트를 제한했다는 메시지가 떠요. 조금 딱딱해질 수 있지만 VRM 변환 때문에 감수해요.

  • Smooth를 많이 하면 한 점에 5~6개 그룹이 걸리기 쉬워요. Smooth를 너무 많이 주지 마세요.
  • 본을 너무 촘촘히 넣으면 오히려 문제가 돼요.

    Ctrl+J는 여러 오브젝트를 하나로 합쳐요. 같이 움직일 것이라 하나로 만들어요.

    머리에 붙은 부분은 움직이지 않게 고정해요.

    Weight Paint → Weights → Smooth 를 그룹마다 4번씩

    루프컷이 많을수록 부드럽지만 리깅 시간이 늘어요. 강사는 단순하게 두고 약간의 찌글거림은 감수했어요. 멀리서 보면 티가 안 나요.

  6. Limit Total 4웨이트

    Weights → Limit Total → Limit 4
    양갈래도 마지막에 점마다 본 4개 제한을 맞춰요.

    Object Data 탭 → Viewport Display 를 Stick 으로 → Names 체크 끄기
