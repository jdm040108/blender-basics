EP.09

옷을 더 사랑스럽게: 옷 텍스처 페인팅

의상의 UV를 새로 펴고 Cloth 이미지 한 장에 베이스 색, 명암, 테두리 선, 주머니 같은 그림을 직접 칠해요. 마지막에 이미지를 저장하고 옷, 몸, 얼굴에 VRM 재질(MToon)과 아웃라인을 넣어요.

강의 영상 열기
의상 컬렉션 만들기의상 UV 펴기Mirror·Subdivision을 Apply한 뒤 다시 반으로 자르기UV 배치(주차)베이스 색 채우기명암(그림자) 칠하기홑겹 면의 테두리 선을 직접 그리기그림으로 디테일 추가바지·양말·신발저장과 VRM 머티리얼(MToon) 설정쉐이더·브러시·해상도 정리

의상 컬렉션 만들기

0:00~0:30

의상 오브젝트가 전용 컬렉션에 모여 있어요.

  1. 의상 컬렉션 만들기파일·설정

    의상 오브젝트만 선택 → 의상 전용 컬렉션을 새로 만들어 넣기
    컬렉션은 오브젝트를 담는 폴더예요. 필요할 때 의상만 골라 볼 수 있어요.

  2. 나머지 옷 숨기기화면

    작업할 한 벌만 남기고 나머지는 눈 아이콘 끄기
    한 벌씩 작업해야 헷갈리지 않아요.

의상 UV 펴기

0:30~7:11

가디건, 블라우스, 리본, 바지, 신발과 양말의 UV가 칠하기 좋게 새로 펴져 있어요.

  1. 가디건 UnwrapUV

    가디건 Edit Mode → 전체 선택 → UV → Unwrap → Angle Based
    UV는 3D 표면을 이미지 위에 펼친 전개도예요. 가디건은 따라온 Seam(절개선) 구성이 괜찮아서 그대로 펴요.

  2. 블라우스 면 정리메시 편집

    블라우스에서 마음에 안 드는 부분의 면 선택 → 삭제
    펴기 전에 필요 없는 면을 정리해요.

  3. 카라만 남기고 숨기기화면

    카라만 선택 → Shift H
    선택한 것만 남기고 나머지를 숨겨요. 카라 안쪽 경계를 고르기 쉬워져요.

  4. 카라 경계 SeamUV

    카라 안쪽(몸판과 만나는 경계) 엣지 선택 → Mark Seam
    카라 때문에 UV가 어색해져서 카라와 몸판을 따로 나눠요.

  5. 숨긴 것 다시 표시화면

    Alt H
    숨겨 둔 면을 다시 보이게 해요.

  6. 블라우스 UnwrapUV

    Unwrap → 불필요하게 조각나는 Seam 은 Clear Seam 후 다시 Unwrap
    몸판 섬 하나와 카라 섬 하나로 나오면 돼요. 섬은 UV 조각 하나를 말해요.

  7. 리본 모디파이어 적용모디파이어

    리본의 Mirror 모디파이어 Apply → Subdivision 모디파이어 Apply
    큐브로 만든 리본은 그대로 펴면 동그랗게 나와 칠하기 어려워요. 모디파이어 결과를 실제 메시로 굳혀요.

  8. 리본 절반 삭제메시 편집

    X-ray 켜기 → 왼쪽 절반 선택 → 삭제
    반쪽만 칠하고 Mirror로 복사하려고 절반을 지워요.

  9. 리본에 Mirror 다시모디파이어

    Mirror 모디파이어 다시 추가 → Clipping 켜기
    지운 절반이 거울처럼 다시 생겨요.

  10. 리본 Seam과 UnwrapUV

    매듭과 날개 각각 절반 지점(앞과 뒤의 경계)에 Mark Seam → Unwrap(첫 번째 항목 Angle Based)
    앞면 섬과 뒷면 섬으로 나뉘어요.

  11. 리본 섬 배치UV

    앞면 섬은 앞면끼리, 뒷면 섬은 뒷면끼리 모아 두기
    칠할 때 어디가 앞인지 바로 알 수 있어요.

  12. 바지 Seam 지우기UV

    바지의 기존 Seam 전부 선택 → Clear Seam
    그냥 펴면 가랑이 안쪽이 꼬여서 절개선을 처음부터 다시 넣어요.

  13. 바지 Seam 새로 넣기UV

    가랑이 안쪽 라인, 다리 부분, 밑단 마감 부분에 Mark Seam → Unwrap
    옷의 재봉선처럼 잘라요. 말려 올라간 롤업 부분, 엉덩이와 아랫배 부분, 다리 안쪽 마감 부분으로 나뉘어요.

  14. 신발·양말 SeamUV

    양말과 신발의 경계 루프에 Mark Seam → 밑창(동그란 면) 둘레에도 Mark Seam → Unwrap
    신발 갑피, 양말, 신발 밑창으로 나뉘어요. 색이 바뀌는 경계에서 잘라 둬야 칠하기 쉬워요.
    양말과 신발 경계에는 반드시 Seam을 넣으세요.

  15. 신발·양말 섬 배치UV

    신발 섬은 신발끼리, 양말 섬은 양말끼리 모아 두기
    같은 색으로 칠할 것끼리 붙여 두면 편해요.

  16. 섬이 어디인지 확인UV

    UV 에디터에서 섬 선택 → 3D 뷰에서 선택된 곳 확인
    어떤 섬이 옷의 어디인지 헷갈릴 때 써요.
의상Seam / Unwrap 방법결과 섬
가디건따라온 Seam 그대로. 전체 선택 → UV → Unwrap → Angle Based
블라우스카라만 선택해 Shift+H → 카라 안쪽 경계에 Mark Seam → Alt+H → Unwrap몸판 섬 + 카라 섬
리본Mirror, Subdivision Apply → 왼쪽 절반 삭제 → Mirror 다시(Clipping 켬) → 매듭과 날개의 앞뒤 경계에 Seam → Unwrap앞면 섬 / 뒷면 섬
바지기존 Seam 전부 Clear → 가랑이 안쪽, 다리 부분, 밑단 마감 부분에 새 Seam롤업 부분 / 엉덩이+아랫배 / 다리 안쪽 마감
신발+양말양말과 신발 경계 루프에 Seam, 밑창에도 Seam신발 갑피 / 양말 / 신발 밑창
강사의 팁
  • 몸에서 복제한 옷은 몸 UV가 따라와 있지만 새로 펴요.

Mirror·Subdivision을 Apply한 뒤 다시 반으로 자르기

7:11~10:24

옷마다 UV가 촘촘해지고, 반쪽만 칠하면 되도록 Mirror가 스택 맨 위에 다시 걸려 있어요.

  1. Mirror Apply모디파이어

    옷 선택 → Mirror 모디파이어 → Apply
    Apply는 모디파이어 결과를 실제 메시로 굳히는 거예요.

  2. Subdivision Apply모디파이어

    Subdivision 모디파이어 → Apply
    옷에는 주머니, 단추 같은 디테일을 그려 넣어요. 면이 촘촘해야 UV도 촘촘해져서 그림이 깨끗하게 나와요.

  3. 쉐이프 키 오류 해결쉐이프 키

    쉐이프 키 때문에 적용할 수 없다는 오류가 뜨면 → 그 오브젝트의 Basis 쉐이프 키 삭제 → 다시 Apply
    쉐이프 키가 있는 메시에는 모디파이어를 적용할 수 없어요. 몸에서 복제할 때 쉐이프 키가 따라온 옷에서 생겨요.
    어느 옷에서 오류가 났는지 강의 자막이 불명확해요(가디건으로 보여요). 오류가 뜨는 옷에만 하세요.

  4. 한쪽 절반 삭제메시 편집

    Edit Mode → X-ray 켜기 → 한쪽 절반 선택 → 삭제
    Mirror를 적용한 채로 펴면 양쪽을 다 칠해야 해요. 반만 칠하려고 다시 반으로 잘라요.
    정중앙 점은 선택에 넣으면 안 돼요.

  5. Mirror 다시 추가모디파이어

    Mirror 모디파이어 추가 → 스택 맨 위(Armature 보다 위)로 올리기 → Clipping 체크
    지운 절반을 거울처럼 다시 만들어요.
    순서가 정말 중요해요. Mirror가 Armature 아래에 있으면 나중에 포즈를 적용했을 때 이상하게 움직여요.
강사의 팁
  • 몸은 거의 단색이라 큰 네모(로우폴리 UV)로 충분했어요. 옷은 주머니, 자수, 와펜, 레이스, 단추 같은 디테일을 그려 넣기 때문에 촘촘한 네모가 필요해요.
  • 리본은 앞 구간에서 이미 처리했어요.
  • 한쪽에만 하트를 넣는 것처럼 좌우가 다른 무늬를 원하면, Mirror를 적용한 상태로 양쪽이 모두 펼쳐진 UV를 배치해야 해요.

UV 배치(주차)

10:24~12:18

모든 의상의 UV 섬이 Cloth 이미지 안에 자리 잡고 있어요.

  1. 모든 섬 한 번에 보기UV

    의상 전부 선택 → Edit Mode → 전체 선택
    모든 옷의 섬이 UV 에디터에 한꺼번에 보여요.

  2. 섬 배치하기UV

    섬을 옮기고 크기를 바꿔 Cloth 이미지 안에 퍼즐 맞추듯 배치
    이미지 한 장에 모든 옷을 담아요.
    섬끼리 적당히 떨어뜨려 두세요. 붙어 있으면 칠할 때 옆 섬으로 번져요.

  3. 안 보이는 섬 작게UV

    리본 섬은 작게, 리본 뒷면 섬은 더 작게, 바지 안쪽 마감 섬도 작게 줄이기
    잘 안 보이는 곳에는 이미지 공간을 조금만 줘요.
강사의 팁
  • 이 영상에서는 체커 텍스처로 밀도를 맞추는 과정을 하지 않아요.

베이스 색 채우기

12:18~17:21

옷마다 기본 색이 채워져 있어요.

  1. Image Editor에서 채우기페인트

    Texture Paint 워크스페이스 → Image Editor → Fill(페인트 통) → 해당 UV 섬 클릭
    섬 하나를 한 가지 색으로 채워요. 강사가 더 좋아하는 방법이에요.

  2. 3D 뷰에서 채우기페인트

    Edit Mode에서 칠할 면(또는 전체) 선택 → Texture Paint 모드 → 페인트 마스크(Face Selection Masking) 켜기 → Fill 로 클릭
    페인트 마스크는 선택한 면에만 칠해지게 해 줘요. 선택된 면만 채워져요.

  3. 가디건 색페인트

    가디건을 따뜻하고 밝은 노란색으로 채우기
    머리와 눈이 파란색이라 대비되는 색을 골랐어요.
    정확한 색 코드는 강의 자막에 없어요. 화면을 보고 맞추세요.

  4. 리본 색페인트

    리본을 머리색과 비슷한 파란 계열로 채우기
    여러 색을 시도한 끝에 고른 색이에요. 빨강은 색동저고리 같다고 뺐어요.
    정확한 색 코드는 강의 자막에 없어요.

  5. 블라우스 색페인트

    블라우스를 살짝 어두운 아이보리로 채우기
    순백색은 하이라이트처럼 보여서 피해요.
    정확한 색 코드는 강의 자막에 없어요.

  6. 바지 색페인트

    바지를 밝은 브라운으로 채우기
    가디건과 같은 노랑이면 정장 세트 같아 보여요. 캐주얼한 느낌으로 가요.
    정확한 색 코드는 강의 자막에 없어요.

  7. 롤업 색페인트

    바지의 말려 올라간 부분을 블라우스와 같은 색으로 채우기
    같은 색을 써서 통일감을 줘요.

  8. 양말 색페인트

    양말 면만 선택 → 따로 칠하기
    신발과 한 메시라서 양말 면만 골라 칠해요.
    양말 색은 강의 자막에 없어요. 화면을 보고 맞추세요.

  9. 신발 색페인트

    신발을 어둡고 검정에 가까운 색으로 채우기
    SD 캐릭터에는 어두운 신발이 잘 어울려요.

  10. 팔레트에 색 추가페인트

    색을 쓸 때마다 팔레트의 + 버튼 누르기
    팔레트는 자주 쓰는 색을 모아 두는 곳이에요. 안 넣어 두면 매번 스포이드로 찍어야 해요.
    강사도 여러 번 잊어서 거듭 강조했어요.
강사의 팁
  • 레이어를 쓰지 않고 Cloth 이미지 한 장에 직접 칠해요.

명암(그림자) 칠하기

17:21~29:44

블라우스, 리본, 가디건의 가려지는 곳에 그림자가 칠해져 있어요.

  1. 명암색 만들기페인트

    각 베이스 색보다 조금 더 어둡고 진한(채도 있는) 색 만들기 → 팔레트에 추가
    그림자로 칠할 색이에요.
    너무 갈색으로 가면 채도를 빼세요. 색 코드는 강의 자막에 없어요.

  2. 그림자 영역 선택선택

    Edit Mode에서 그림자가 질 영역의 면 선택
    큰 덩어리를 한 번에 채우려고 미리 골라요.

  3. 마스크 켜고 Fill페인트

    Texture Paint 모드 → 페인트 마스크 켜기 → Fill 로 클릭
    선택한 면에만 그림자색이 채워져요.

  4. 마스크 끄고 다듬기페인트

    페인트 마스크 끄기 → 브러시로 경계를 이어 다듬기
    면 단위로 채우면 경계가 각져요. 손으로 이어 줘야 자연스러워요.

  5. 선택 뒤집기선택

    Ctrl I
    선택된 것과 안 된 것을 맞바꿔요. 반대쪽을 칠할 때 써요.

  6. 과한 곳 지우기페인트

    베이스 색을 골라 과하게 칠한 곳 덮기
    지우개 대신 원래 색으로 덮어서 고쳐요.

  7. 블라우스 명암페인트

    카라와 목 근처 영역을 통째로 어둡게 칠하기 → 리본에 가려지는 부분, 가디건에 가려지는 부분에도 그림자 그리기 → 안 보이는 속 부분도 칠하기
    몸의 목 아래를 어둡게 칠했던 것과 맞춰요. 속까지 칠해 둬야 안 칠한 것처럼 보이지 않아요.

  8. 리본 명암페인트

    옷과 카라에 가려지는 안쪽 면을 어둡게 → 매듭에서 바깥으로 퍼지는 접힌 주름 명암 그리기
    주름 명암이 리본의 매력이에요.
    주름살처럼 과해지면 다시 그리세요. 옆에서 봤을 때도 명암이 이어지게 하세요.

  9. Wireframe 켜기화면

    Overlays → Wireframe 켜기
    메시의 선이 보여서 어깨선이 어디인지 알 수 있어요.

  10. 가디건 명암페인트

    어깨 라인에 맞춰 목 주변 명암(어깨선을 넘지 않게) → 뒤쪽은 둥글게 퍼지도록 → 리본이 드리우는 그림자 → 소매 끝
    가려지는 곳에 그림자를 넣어 입체감을 줘요.
    팔과 어깨처럼 움직이는 부위에 걸쳐 명암을 넣으면 포즈에 따라 우글거려 보여요. 목 주변 명암은 어깨 영역까지만 넣으세요.

    Alt+S는 면 방향으로 부풀리거나 줄여요. 작업 중 발견한 뚫림을 바로 고쳐요.

홑겹 면의 테두리 선을 직접 그리기

26:43~29:44, 33:26~37:04

아웃라인이 안 생기는 가디건 앞섶과 카라 가장자리에 테두리 선이 그려져 있어요.

  1. Stroke를 Line으로페인트

    브러시 Stroke Method → Line
    드래그한 시작점과 끝점 사이에 직선이 그어져요.

  2. 가디건 테두리 긋기페인트

    Image Editor(UV 창)에서 가디건 UV 섬 가장자리를 따라 직선 긋기 → 소매 끝은 더 두껍게
    가디건 앞섶처럼 한 장짜리 면(홑겹)의 가장자리에는 MToon 아웃라인이 생기지 않아요. 텍스처에 선을 직접 그려요.
    브러시 크기 수치는 강의 자막에 없어요.

  3. Stroke를 Space로페인트

    Stroke Method → Space 로 되돌리기
    보통 브러시처럼 자유롭게 그리는 방식으로 돌아가요.

  4. 선 다듬기페인트

    베이스 색(노랑)으로 너무 두껍거나 딱딱한 부분 다듬기
    선 굵기를 고르게 맞춰요.
    계단처럼 보여도 멀리서 보면 티가 안 나요.

  5. 카라 테두리 긋기페인트

    검은색 고르기 → Stroke Method Line → 블라우스 카라 가장자리에 테두리 그리기
    카라도 홑겹이라 아웃라인이 안 생겨요.
    강사는 처음에 너무 얇게 그려서 두 배 두께로 다시 그렸어요. 전체를 보면서 두께를 정하세요. 선 두께는 균일한 게 가장 좋아요.

  6. 카라에 칠이 안 될 때음영·노멀

    카라 면만 선택 → 노멀을 일시적으로 뒤집기(Flip) → 칠하기
    노멀은 면이 향하는 방향이에요. 면이 뒤집혀(Face Orientation 빨강) 있으면 칠이 안 돼요.
    칠한 뒤 다시 되돌리는지는 강의 자막에 없어요. 화면을 보고 확인하세요.

  7. 삐져나감 확인페인트

    블라우스의 다른 영역으로 선이 삐져나가지 않았는지 확인
    UV 창에서 그은 선이 옆 섬에 묻을 수 있어요.
